Paths and distances

Physical distance is often irrelevant in a network. What matters is how many links separate two nodes.

A path is a sequence of nodes in which each node is linked to the next; its length is the number of links it uses. The shortest path between $i$ and $j$ is a path with the fewest links, and its length is the distance $d_{ij}$. There can be several shortest paths of the same length. Two summaries describe a whole network:

$$d_{\max} = \max_{i,j} d_{ij} \;\;(\text{the diameter}), \qquad \langle d\rangle = \frac{1}{N(N-1)}\sum_{i \ne j} d_{ij} \;\;(\text{the average distance}).$$

(For a network with several components, $d_{ij} = \infty$ between components, so both are computed within the giant component.)

Breadth-first search

Distances are found with breadth-first search (BFS, the book's Box 2.5). Start at a node $s$ and label it 0. Its neighbours get label 1; their unlabelled neighbours get label 2; and so on. Each node is labelled when it is first reached, and its label is its distance from $s$. The search visits every node and link once, so it takes time proportional to $N + L$.

Shortest paths between two nodes

Between members 14 and 16, the two furthest apart in the club, there are 14 different shortest paths of length 5, all running through the instructor, node 0. The number of shortest paths that pass through a node is the idea behind betweenness centrality (see the Network lab).

Distances in real networks

For large networks, computing all $N(N-1)/2$ distances is expensive, so the notebook runs BFS from a random sample of 300 source nodes in the giant component. Each search measures the distance from its source to every other node, so 300 searches in the collaboration network already sample more than six million distances.

Most pairs of scientists are 4 to 6 steps apart, and 84% of pairs are within six steps, yet the network has 23,133 nodes. The power grid is the exception, at about 19 steps on average. A spatial network built to connect neighbouring places cannot have shortcuts across the continent. Chapter 3 explains why distances are short in most networks.

A network has diameter $d_{\max} = 10$. What can you say about its average distance?

  1. $\langle d\rangle = 5$
  2. $\langle d\rangle = 10$
  3. $1 \le \langle d\rangle \le 10$, and usually much closer to the typical than to the maximal distance
  4. $\langle d\rangle > 10$ is possible
The diameter is the single largest distance, often set by a few peripheral nodes; the average is dominated by typical pairs. In the karate club $d_{\max} = 5$ but $\langle d\rangle = 2.41$.
