Intro to graph machine learning

Network science summarises a whole network in a few numbers. Machine learning needs a description of every node, pair or graph, as a vector a classifier can use. This page builds that description by hand, from what the course already measures; the next page learns it.

  • Earlier chapters describe networks with a few numbers ($\langle k\rangle$, $C$, $\gamma$); prediction needs a description of every node.
  • Hand-made features reuse what the course already measures: degree, clustering, paths, random walks.
  • Embeddings learn the features instead; graph neural networks learn them for the task at hand.

Every task needs a vector per node (or pair, or graph). The classic pipeline computes it by hand and feeds it to a standard model such as logistic regression or a random forest.

Hand-made features: nodes

How important is a node? Each centrality answers a different version of the question.

Worked example 1: eigenvector centrality of a star. A hub with $n$ leaves.

  1. Each leaf's only neighbour is the hub: $\lambda c_{\text{leaf}} = c_{\text{hub}}$. The hub has $n$ leaf neighbours: $\lambda c_{\text{hub}} = n\,c_{\text{leaf}}$.
  2. Multiply: $\lambda^2 = n$, so $\lambda = \sqrt n$ and $c_{\text{leaf}} = c_{\text{hub}}/\sqrt n$.
  3. With 4 leaves: $\lambda = 2$, leaves score half the hub. Degree would say a quarter: a leaf gains from its one important neighbour.

Worked example 2: PageRank by hand. Directed links $A \to B$, $A \to C$, $B \to C$, $C \to A$, $D \to C$; start from $r = \frac14$ each.

  1. Simplified PageRank ($d = 1$): each node splits its score equally over its out-links. Iteration 1: $A$ receives all of $C$'s $0.25$; $B$ half of $A$'s, $0.125$; $C$ half of $A$'s plus all of $B$'s and $D$'s, $0.625$; $D$ receives nothing, $0$.
  2. Iteration 2: $A = 0.625$, $B = 0.125$, $C = 0.250$, $D = 0$. It converges to $A = 0.4$, $B = 0.2$, $C = 0.4$, $D = 0$.
  3. With $d = 0.85$ every node first gets $0.15/4 = 0.0375$: $D$ keeps $0.038$ instead of 0, and the result is $A = 0.373$, $B = 0.196$, $C = 0.394$. Teleporting stops scores from draining into dead ends and keeps the walk from getting trapped.

Hand-made features: pairs of nodes

For link prediction, score each unlinked pair $u, v$:

  • Distance $d_{uv}$: short is likely, but it ignores how many paths there are.
  • Common neighbours $|N(u) \cap N(v)|$; Jaccard divides by $|N(u) \cup N(v)|$.
  • Adamic–Adar $\sum_{w \in N(u)\cap N(v)} 1/\ln k_w$ and resource allocation $\sum_w 1/k_w$: a shared low-degree neighbour says more than a shared hub.
  • Preferential attachment $k_u k_v$, from the BA model.
  • Katz index: count all walks between $u$ and $v$, damping long ones:
    $$S_{uv} = \sum_{\ell \ge 1}\beta^\ell (A^\ell)_{uv}, \qquad S = (I - \beta A)^{-1} - I, \qquad \beta < 1/\lambda_{\max}.$$

The first scores are local (they see only shared neighbours, so they give 0 to pairs at distance 3 or more); Katz is global.

Worked example 3: Katz on a square. Nodes $A, B, C, D$ in a 4-cycle; $\lambda_{\max} = 2$, so $\beta < 0.5$.

  1. Opposite corners $A, C$ share 2 neighbours but are not linked. Walks from $A$ to $C$: 2 of length 2, 8 of length 4, and so on (none of odd length).
  2. $\beta = 0.1$: $S_{AC} = 2(0.01) + 8(0.0001) + \dots = 0.021$. Adjacent corners: $S_{AB} = 0.104$.
  3. $\beta = 0.4$: $S_{AC} = 0.89$, $S_{AB} = 1.11$. Close to $1/\lambda_{\max}$ long walks dominate and the scores blow up; at $\beta \ge 0.5$ the sum diverges.

Evaluate by hiding links: AUC = probability that a hidden link outscores a random non-link (a tie counts as ½). 0.5 is guessing, 1 perfect.

Hand-made features: whole graphs

To classify graphs we need to compare them. Counting small subgraphs (graphlets) works but is expensive. The Weisfeiler–Lehman (WL) method is cheap: give every node the same colour, then repeatedly recolour each node by its own colour and the multiset of its neighbours' colours:

$$c^{(t+1)}(v) = \operatorname{hash}\Big(c^{(t)}(v),\ \{\!\{c^{(t)}(u) : u \in N(v)\}\!\}\Big).$$

After $t$ rounds a node's colour summarises its neighbourhood up to distance $t$. Two graphs whose colour counts differ are certainly different (not isomorphic); the counts, as a vector, are the WL graph features. If the counts never differ, WL cannot tell the graphs apart, even when they are different.

Worked example 4: WL by hand. Graph 1 is a path of 5 nodes, $a{-}b{-}c{-}d{-}e$; graph 2 is a triangle plus a separate link. Both have degrees $\{1, 1, 2, 2, 2\}$.

  1. Round 1 (colour = degree): both graphs have two nodes of colour 1 and three of colour 2. Not yet distinguished.
  2. Round 2 (own colour + neighbours' colours): path: $a, e \to (1; 2)$, $b, d \to (2; 1, 2)$, $c \to (2; 2, 2)$. Triangle plus link: link ends $\to (1; 1)$, triangle nodes $\to (2; 2, 2)$.
  3. The colour counts now differ, so the graphs are different. But a 6-cycle and two triangles stay identical forever: every node has degree 2 and two degree-2 neighbours in both.

In simplified PageRank (no teleporting, $d = 1$), node $D$ has out-links but no in-links. What is its score after the first iteration, and why does real PageRank use $d < 1$?

  1. It keeps its starting score, because it has out-links
  2. It becomes the largest, because it gives score to others
  3. It drops to 0; teleporting gives every node a floor of $(1-d)/N$ and stops the walk from getting trapped
  4. It is undefined; $d < 1$ only makes the computation faster
A node's new score is what flows in along links. Without teleporting, nodes without in-links drop to 0 and dead ends or closed loops can trap the walk; $d = 0.85$ fixes both.

The largest eigenvalue of a network's adjacency matrix is $\lambda_{\max} = 4$. For which damping $\beta$ is the Katz index $\sum_{\ell} \beta^\ell (A^\ell)_{uv}$ defined?

  1. $\beta < 1$
  2. $\beta < 0.25$
  3. $\beta > 0.25$
  4. Any $\beta > 0$
Walk counts grow like $\lambda_{\max}^\ell$, so $\beta^\ell\lambda_{\max}^\ell$ must shrink: $\beta < 1/\lambda_{\max} = 0.25$.

The Weisfeiler–Lehman test is run on a 6-cycle and on two separate triangles. What does it report?

  1. No difference, in any round: every node has degree 2 and two degree-2 neighbours in both graphs
  2. A difference in round 1
  3. A difference in round 2, when the triangles appear
  4. That the graphs are isomorphic
WL can only prove two graphs different. Here it never can, although they differ (one is connected, the other has triangles), and neither can any message-passing GNN.
