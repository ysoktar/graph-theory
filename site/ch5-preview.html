The Barabási–Albert model

Chapter 4 showed that real networks have hubs, but not why they have them. The random network has no hubs, and the configuration model only reproduces the hubs we put into it. What simple process, repeated while a network grows, creates hubs on its own?

  • The random network and the configuration model are descriptive: they tell us what a network with given properties looks like.
  • The Barabási–Albert (BA) model is mechanistic: it tells us how a network came to look that way.
  • A mechanism can predict how a network will grow, explain why unrelated systems share the same pattern, and show which change in the rules would remove it.

Growth and preferential attachment (Section 5.3)

  • Growth: new nodes keep arriving, such as new web pages, papers or users.
  • Preferential attachment: newcomers link more often to nodes that already have many links.

The model starts with $m_0$ linked nodes. At each step one new node arrives with $m \le m_0$ links, and each link attaches to an existing node $i$ with probability

$$\Pi(k_i) = \frac{k_i}{\sum_j k_j}.$$
$\Pi(k_i)$
probability that one new link lands on node $i$
$k_i$
current degree of node $i$
$\sum_j k_j$
sum of all degrees, about $2mt$ after $t$ steps
$m$
number of links each new node brings

Worked example: who gets the next link?

  1. Given: $m = 2$, after $t = 1{,}000$ steps.
  2. Each step adds $m$ links and each link adds 2 to the total degree, so $\sum_j k_j \approx 2mt = 4{,}000$.
  3. A node with 40 links: $\Pi = 40/4{,}000 = 1\%$ per new link. A node with 2 links: $2/4{,}000 = 0.05\%$.
  4. Meaning: the hub is twenty times more likely to win each link, so it pulls further ahead: the rich get richer.

Time in networks (Box 5.2). The WWW added a page about every millisecond; the cell added a gene about every 200,000 years. To compare them we count event time: $t$ advances by one each time a node arrives, so $t = N$ in the BA model.

Why the result is a power law (Sections 5.4–5.5)

Treat time $t$ and degree $k$ as continuous numbers (the continuum approximation). Then:

  1. Each step brings $m$ links, each landing on $i$ with probability $\Pi(k_i)$, and the degrees add up to $\sum_j k_j = 2mt - m \approx 2mt$. So node $i$ grows at the rate $\dfrac{dk_i}{dt} = m\,\Pi(k_i) = \dfrac{m\,k_i}{2mt} = \dfrac{k_i}{2t}$.
  2. Separate the variables, $\dfrac{dk_i}{k_i} = \dfrac{dt}{2t}$, and integrate from the arrival time $t_i$, when $k_i = m$: $\ln\dfrac{k_i}{m} = \tfrac12\ln\dfrac{t}{t_i}$, that is $k_i(t) = m\,(t/t_i)^{1/2}$. Its growth rate $dk_i/dt = m/(2\sqrt{t\,t_i})$ falls with time: fewer and fewer new links go to any one node.
  3. A node has fewer than $k$ links if it arrived after $t_i = m^2 t/k^2$. Nodes arrive at a steady rate, so $P(K < k) = 1 - m^2/k^2$.
  4. Differentiating this with respect to $k$ gives $p_k \approx 2m^2 k^{-3}$.
$t$
time, counted as the number of nodes added
$t_i$
arrival time of node $i$
$1/2$
the dynamical exponent $\beta$: every degree grows like $\sqrt{t}$
$p_k$
fraction of nodes with degree $k$
$k^{-3}$
a power law with degree exponent $\gamma = 3$

Older nodes are further ahead, which is called the first-mover advantage. The exact solution (Eq. 5.11, Section 5.5; derived in Advanced Topic 5.A) is

$$p_k = \frac{2m(m+1)}{k(k+1)(k+2)} \qquad (k \ge m).$$
  • The exponent is $\gamma = 3$ for every $m$ and every starting network.
  • The largest hub grows like $k_{\max} \sim m N^{1/2}$, the natural cutoff of a power law with $\gamma = 3$ (The largest hub).

For $m = 2$, the exact formula gives $p_2 = \frac{2\cdot2\cdot3}{2\cdot3\cdot4} = \frac12$; in general $p_m = 2/(m+2)$. For $k = 10$ it gives $p_{10} = 0.009$, against $0.008$ from the continuum formula.

Two more properties follow. The distribution is stationary: it does not depend on $t$ or $N$, which is why networks of very different age and size can share it. And its prefactor grows like $m(m+1) \approx m^2$, so $p_k/2m^2$ falls on a single curve for every $m$.

Both ingredients are needed (Section 5.6)

Is the power law caused by growth, by preferential attachment, or by both? Remove one at a time.

  • Model A, growth without preference: $\Pi(k_i) = 1/(m_0 + t - 1)$. The rate $dk_i/dt = m/(m_0 + t - 1)$ gives $k_i(t) = m\ln\big(e\,\frac{m_0 + t - 1}{m_0 + t_i - 1}\big) \approx m \ln(e\,t/t_i)$, only logarithmic growth, and an exponential distribution $$p_k = \frac{e}{m}\exp\Big(-\frac{k}{m}\Big).$$
  • Model B, preference without growth: $N$ is fixed and each step adds one link between a random node and a node chosen with $\Pi(k)$. Every degree grows linearly, $k_i(t) \approx 2t/N$; the distribution keeps changing and ends as a complete graph with $p_k = \delta(k - N + 1)$.

Both ingredients are needed: without preferential attachment the tail is exponential and no hubs form; without growth there is no stationary distribution at all. Together they are sufficient for a scale-free network with $\gamma = 3$.

Measuring preferential attachment (Section 5.7)

Preferential attachment makes two claims: the chance of gaining a link depends on $k$ (hypothesis 1), and the dependence is linear (hypothesis 2). Both can be tested with two maps of the same network taken a short time $\Delta t$ apart. For each node, the links it gained estimate $\Pi(k)$:

$$\Pi(k) \sim \frac{\Delta k_i}{\Delta t}, \qquad \pi(k) = \sum_{k_i = 0}^{k} \Pi(k_i).$$
$\Delta k_i$
links node $i$ gained between the two maps, grouped by its degree $k_i$ in the first map
$\pi(k)$
cumulative attachment function: summing smooths the noise of single degrees

If $\Pi(k) \sim k^\alpha$, then $\pi(k) \sim k^{\alpha + 1}$: no preference gives slope 1, linear preference slope 2. The Internet and citation networks give $\alpha \approx 1$; co-authorship and actors $\alpha = 0.9 \pm 0.1$, slightly sublinear.

Nonlinear preferential attachment (Section 5.8)

What if $\Pi(k) \sim k^\alpha$ with $\alpha \ne 1$?

  • $\alpha = 0$: no preference, Model A: exponential $p_k$.
  • $0 < \alpha < 1$, sublinear: a stretched exponential, $p_k \sim k^{-\alpha}\exp\!\big(-\frac{2\mu(\alpha)}{\langle k\rangle(1-\alpha)}k^{1-\alpha}\big)$, with fewer and smaller hubs; the largest grows only like $k_{\max} \sim (\ln t)^{1/(1-\alpha)}$.
  • $\alpha = 1$: the BA power law, $k_{\max} \sim t^{1/2}$.
  • $\alpha > 1$, superlinear: winner takes all. The earliest nodes become super-hubs holding a finite share of all links, $k_{\max} \sim t$, and the network turns hub-and-spoke.

Only exactly linear attachment gives a pure power law; a slightly sublinear $\Pi(k)$, as measured for collaborations, is one reason real tails bend down.

Worked example: reading α from data.

  1. Given: on log–log axes the measured $\pi(k)$ of a network rises from 0.01 at $k = 2$ to 0.79 at $k = 20$.
  2. Slope $= \log_{10}(0.79/0.01)/\log_{10}(20/2) = \log_{10} 79 = 1.9$.
  3. $\pi(k) \sim k^{\alpha+1}$, so $\alpha = 1.9 - 1 = 0.9$: sublinear.
  4. Meaning: expect a slightly curved tail (stretched exponential) and smaller hubs than the BA model predicts.

Where does preferential attachment come from? (Section 5.9)

Nobody computes $\Pi(k)$ before linking. Two kinds of mechanism produce it anyway.

  • Link selection (local, random): a new node picks a random link and attaches to one of its two ends. The end of a random link is a degree-$k$ node with probability $$q_k = \frac{k\,p_k}{\langle k\rangle},$$ linear in $k$: preferential attachment without knowing any degree.
  • Copying (local, random): a new web page picks a random page $u$; with probability $p$ it links to $u$, otherwise it copies one of $u$'s links. A node is reached with probability $$\Pi(k) = \frac{p}{N} + (1-p)\frac{k}{2L},$$ again linear. Friends of friends, copied references and duplicated genes work this way.
  • Optimization (global, rational): a new node at a random point of a unit square links to the node $j$ that minimises a cost $C_j = \delta\,d_{ij} + h_j$, trading the distance $d_{ij}$ against the network distance $h_j$ of $j$ from a central node. Small $\delta$ gives a star, large $\delta$ ($\ge \sqrt N$) a network without hubs, and in between ($4 \le \delta \le \sqrt N$) a scale-free network: each node attracts the newcomers that land in its basin, and bigger nodes have bigger basins.

Luck or reason: in the 1960s Herbert Simon (random, preferential growth) and Benoit Mandelbrot (optimization) fought over the origin of power laws in word frequencies. Both mechanisms turn out to produce linear preferential attachment.

Distances and clustering (Section 5.10)

$$d_{\max} \sim \frac{\ln N}{\ln\ln N}\ (m > 1), \qquad \langle C\rangle \sim \frac{(\ln N)^2}{N}.$$
$d_{\max}$
diameter; the average distance scales the same way, slower than the random network's $\ln N$
$\langle C\rangle$
average clustering; above the random $\langle k\rangle/N$ but still vanishing for large $N$

The BA model's lesson is that structure and evolution are inseparable. Random, small-world and configuration models are like a photograph of a painting: they reproduce what a network looks like. The BA model repaints it with the original brush strokes: to explain a network's topology, model how it came to be.

  • The BA model explains the power law of Chapter 4. Its exponent $\gamma = 3$ lies on the border of the scale-free regime, where $\langle k^2\rangle$ grows only like $\ln N$.
  • It generates the degree sequence that the configuration model takes as input; its old nodes are also linked to each other in a non-random way.
  • The fitness model generalizes it: nodes grow at different rates, so latecomers can win.

The BA model always gives $\gamma = 3$, yet the book's networks have exponents from 1.9 to 4.8 and much higher clustering. What is the model missing?

Possible ingredients are fitness (Ch 6), links that are added or removed between existing nodes, nonlinear attachment $\Pi \sim k^\alpha$ (with $\alpha \ne 1$ the power law breaks down) and ageing. The clustering of the BA model vanishes as $(\ln N)^2/N$.

The degrees add up to $2L = 10{,}000$, so $\Pi = 50/10{,}000 = 0.5\%$.

  1. About half
  2. Almost none
  3. All of them
  4. About 1%
$p_2 = 1/2$: most nodes stay small, and only a few early nodes become hubs.

Why does the BA model give $\gamma = 3$ whatever the value of $m$?

  1. Because the exponent is defined to be 3
  2. Because the starting network has three nodes
  3. Because no node can have more than three links
  4. Because $m$ cancels in the growth rate, $dk_i/dt = k_i/(2t)$
More links per newcomer also means a proportionally larger total degree to compete with. Every node therefore grows with $\beta = 1/2$, and $\gamma = 1 + 1/\beta = 3$.

  3. Like $N^{1/2}$
  4. Like $\ln N$
At $\gamma = 3$, $\langle k^2\rangle \sim \ln k_{\max} \sim \ln N$: the border case (The role of γ).

In the link selection model a new node picks a random link and attaches to one of its ends. The end of a random link is a degree-$k$ node with probability $q_k = k\,p_k/\langle k\rangle$. Why does this model produce a scale-free network?

  1. The new node chooses the node with the most links
  2. Because the network grows
  3. It minimises the distance to the centre
  4. Hubs sit at the end of many links, so a random link reaches a node with probability proportional to its degree: preferential attachment without any rule
$q_k \propto k$ is linear preferential attachment in disguise. Together with growth it reproduces the BA model and $\gamma = 3$.

Measured between two snapshots, a network's cumulative attachment function grows as $\pi(k) \sim k^{2.4}$. With $\pi(k) \sim k^{\alpha + 1}$, what kind of network should grow?

  1. A BA network with $\gamma = 3$
  2. $\alpha = 1.4$, superlinear: a few early super-hubs take a finite share of all links, a hub-and-spoke network
  3. $\alpha = 1.4$, sublinear: a stretched exponential with small hubs
  4. An exponential degree distribution
$\alpha = 2.4 - 1 = 1.4 > 1$: the rich-get-richer effect is amplified into winner takes all, and $k_{\max}$ grows linearly in time.
