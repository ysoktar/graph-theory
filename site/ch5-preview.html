The Barabási–Albert model

Chapter 4 showed that real networks have hubs, but not why they have them. The random network has no hubs, and the configuration model only reproduces the hubs we put into it. What simple process, repeated while a network grows, creates hubs on its own?

  • The random network and the configuration model are descriptive: they tell us what a network with given properties looks like.
  • The Barabási–Albert (BA) model is mechanistic: it tells us how a network came to look that way.
  • A mechanism can predict how a network will grow, explain why unrelated systems share the same pattern, and show which change in the rules would remove it.

Growth and preferential attachment (Section 5.3)

  • Growth: new nodes keep arriving, such as new web pages, papers or users.
  • Preferential attachment: newcomers link more often to nodes that already have many links.

The model starts with $m_0$ linked nodes. At each step one new node arrives with $m \le m_0$ links, and each link attaches to an existing node $i$ with probability

$$\Pi(k_i) = \frac{k_i}{\sum_j k_j}.$$
$\Pi(k_i)$
probability that one new link lands on node $i$
$k_i$
current degree of node $i$
$\sum_j k_j$
sum of all degrees, about $2mt$ after $t$ steps
$m$
number of links each new node brings

After $t = 1{,}000$ steps with $m = 2$, the degrees add up to about 4,000. A node with 40 links then receives each new link with probability $\Pi = 1\%$, and a node with 2 links with probability $0.05\%$. The hub grows twenty times faster.

Why the result is a power law (Sections 5.4–5.5)

Treat time $t$ and degree $k$ as continuous numbers (the continuum approximation). Then:

  1. Each step brings $m$ links, so node $i$ grows at the rate $\dfrac{dk_i}{dt} = m\,\Pi(k_i) = \dfrac{m\,k_i}{2mt} = \dfrac{k_i}{2t}$.
  2. Node $i$ arrives at time $t_i$ with $m$ links; solving the rate equation gives $k_i(t) = m\,(t/t_i)^{1/2}$.
  3. A node has fewer than $k$ links if it arrived after $t_i = m^2 t/k^2$. Nodes arrive at a steady rate, so $P(K < k) = 1 - m^2/k^2$.
  4. Differentiating this with respect to $k$ gives $p_k \approx 2m^2 k^{-3}$.
$t$
time, counted as the number of nodes added
$t_i$
arrival time of node $i$
$1/2$
the dynamical exponent $\beta$: every degree grows like $\sqrt{t}$
$p_k$
fraction of nodes with degree $k$
$k^{-3}$
a power law with degree exponent $\gamma = 3$

Older nodes are further ahead, which is called the first-mover advantage. The exact solution (Eq. 5.11, Section 5.5; derived in Advanced Topic 5.A) is

$$p_k = \frac{2m(m+1)}{k(k+1)(k+2)} \qquad (k \ge m).$$
  • The exponent is $\gamma = 3$ for every $m$ and every starting network.
  • The largest hub grows like $k_{\max} \sim m N^{1/2}$, the natural cutoff of a power law with $\gamma = 3$ (The largest hub).

For $m = 2$, the exact formula gives $p_2 = \frac{2\cdot2\cdot3}{2\cdot3\cdot4} = \frac12$; in general $p_m = 2/(m+2)$. For $k = 10$ it gives $p_{10} = 0.009$, against $0.008$ from the continuum formula.

Both ingredients are needed (Section 5.6). Growth without preference gives an exponential degree distribution (the "uniform attachment" curve above). Preference without growth never settles into a power law: links keep being added until the network is complete.

  • The BA model explains the power law of Chapter 4. Its exponent $\gamma = 3$ lies on the border of the scale-free regime, where $\langle k^2\rangle$ grows only like $\ln N$.
  • It generates the degree sequence that the configuration model takes as input; its old nodes are also linked to each other in a non-random way.
  • The fitness model generalizes it: nodes grow at different rates, so latecomers can win.

The BA model always gives $\gamma = 3$, yet the book's networks have exponents from 1.9 to 4.8 and much higher clustering. What is the model missing?

Possible ingredients are fitness (Ch 6), links that are added or removed between existing nodes, nonlinear attachment $\Pi \sim k^\alpha$ (with $\alpha \ne 1$ the power law breaks down) and ageing. The clustering of the BA model vanishes as $(\ln N)^2/N$.

Since $k_i \propto (t/t_i)^{1/2}$, the ratio is $k_A/k_B = (t_B/t_A)^{1/2} = 10$ at every time $t$.

The degrees add up to $2L = 10{,}000$, so $\Pi = 50/10{,}000 = 0.5\%$.

  1. About half
  2. Almost none
  3. All of them

$p_2 = 1/2$: most nodes stay small, and only a few early nodes become hubs.

Why does the BA model give $\gamma = 3$ whatever the value of $m$?

  1. Because the exponent is defined to be 3
  2. Because the starting network has three nodes
  3. Because no node can have more than three links
  4. Because $m$ cancels in the growth rate, $dk_i/dt = k_i/(2t)$
More links per newcomer also means a proportionally larger total degree to compete with. Every node therefore grows with $\beta = 1/2$, and $\gamma = 1 + 1/\beta = 3$.

The BA model has $\gamma = 3$. How does its second moment $\langle k^2\rangle$ grow with the network size $N$?

  1. It stays finite
  2. Like $N$
  3. Like $N^{1/2}$
  4. Like $\ln N$
At $\gamma = 3$, $\langle k^2\rangle \sim \ln k_{\max} \sim \ln N$: the border case (The role of γ).

In a large BA network with $m = 3$, what fraction of the nodes have exactly 3 links?

  4. About $3/N$
The exact formula gives $p_m = 2/(m+2) = 2/5$.

New nodes keep arriving, but each link attaches to an existing node chosen uniformly at random. What degree distribution results?

  1. A power law with $\gamma = 3$

Without preference, old nodes gain only from their head start, and $p_k$ decays exponentially (Section 5.6).
