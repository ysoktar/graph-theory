The Barabási–Albert model

Chapter 4 showed that real networks have hubs, but not why they have them. The random network has no hubs, and the configuration model only reproduces the hubs we put into it. What simple process, repeated while a network grows, creates hubs on its own?

  • The random network and the configuration model are descriptive: they tell us what a network with given properties looks like.
  • The Barabási–Albert (BA) model is mechanistic: it tells us how a network came to look that way.
  • A mechanism can predict how a network will grow, explain why unrelated systems share the same pattern, and show which change in the rules would remove it.

Growth and preferential attachment (Section 5.3)

  • Growth: new nodes keep arriving, such as new web pages, papers or users.
  • Preferential attachment: newcomers link more often to nodes that already have many links.

The model starts with $m_0$ linked nodes. At each step one new node arrives with $m \le m_0$ links, and each link attaches to an existing node $i$ with probability

$$\Pi(k_i) = \frac{k_i}{\sum_j k_j}.$$
$\Pi(k_i)$
probability that one new link lands on node $i$
$k_i$
current degree of node $i$
$\sum_j k_j$
sum of all degrees, about $2mt$ after $t$ steps
$m$
number of links each new node brings

Worked example: who gets the next link?

  1. Given: $m = 2$, after $t = 1{,}000$ steps.
  2. Each step adds $m$ links and each link adds 2 to the total degree, so $\sum_j k_j \approx 2mt = 4{,}000$.
  3. A node with 40 links: $\Pi = 40/4{,}000 = 1\%$ per new link. A node with 2 links: $2/4{,}000 = 0.05\%$.
  4. Meaning: the hub is twenty times more likely to win each link, so it pulls further ahead: the rich get richer.

Time in networks (Box 5.2). The WWW added a page about every millisecond; the cell added a gene about every 200,000 years. To compare them we count event time: $t$ advances by one each time a node arrives, so $t = N$ in the BA model.

Making the model precise: the linearized chord diagram (Box 5.1)

The definition above leaves details open: how the first $m_0$ nodes are linked, and whether a new node's $m$ links are added together (then two could land on the same node) or one by one. Bollobás and collaborators fixed this with the linearized chord diagram (LCD). For $m = 1$, start from an empty graph; at step $t$ add node $v_t$ and one link from it to node $v_i$ with probability

$$P(i) = \begin{cases} \dfrac{k_i}{2t - 1} & 1 \le i \le t - 1 \\[2mm] \dfrac{1}{2t - 1} & i = t \ (\text{a self-loop}) \end{cases}$$

The new link already counts towards $v_t$'s own degree, so the normalisation is $2t - 1$. Self-loops and multi-links are allowed, but their share vanishes as $t \to \infty$. For $m > 1$ the $m$ links are added one at a time in the same way.

Worked example: the first three steps ($m = 1$).

  1. $t = 1$: node 1 can only link to itself, a self-loop, so $k_1 = 2$.
  2. $t = 2$: node 2 links to node 1 with probability $k_1/3 = 2/3$, or to itself with $1/3$.
  3. $t = 3$, if node 2 chose node 1 ($k_1 = 3$, $k_2 = 1$): node 3 links to node 1 with probability $3/5$, to node 2 with $1/5$, to itself with $1/5$. The hub is already three times as attractive.

Why the result is a power law (Sections 5.4–5.5)

Treat time $t$ and degree $k$ as continuous numbers (the continuum approximation). Then:

  1. Each step brings $m$ links, each landing on $i$ with probability $\Pi(k_i)$, and the degrees add up to $\sum_j k_j = 2mt - m \approx 2mt$. So node $i$ grows at the rate $\dfrac{dk_i}{dt} = m\,\Pi(k_i) = \dfrac{m\,k_i}{2mt} = \dfrac{k_i}{2t}$.
  2. Separate the variables, $\dfrac{dk_i}{k_i} = \dfrac{dt}{2t}$, and integrate from the arrival time $t_i$, when $k_i = m$: $\ln\dfrac{k_i}{m} = \tfrac12\ln\dfrac{t}{t_i}$, that is $k_i(t) = m\,(t/t_i)^{1/2}$. Its growth rate $dk_i/dt = m/(2\sqrt{t\,t_i})$ falls with time: fewer and fewer new links go to any one node.
  3. A node has fewer than $k$ links if it arrived after $t_i = m^2 t/k^2$. Nodes arrive at a steady rate, so $P(K < k) = 1 - m^2/k^2$.
  4. Differentiating this with respect to $k$ gives $p_k \approx 2m^2 k^{-3}$.
$t$
time, counted as the number of nodes added
$t_i$
arrival time of node $i$
$1/2$
the dynamical exponent $\beta$: every degree grows like $\sqrt{t}$
$p_k$
fraction of nodes with degree $k$
$k^{-3}$
a power law with degree exponent $\gamma = 3$

Older nodes are further ahead, which is called the first-mover advantage. The exact solution (Eq. 5.11, Section 5.5; derived in Advanced Topic 5.A) is

$$p_k = \frac{2m(m+1)}{k(k+1)(k+2)} \qquad (k \ge m).$$
  • The exponent is $\gamma = 3$ for every $m$ and every starting network.
  • The largest hub grows like $k_{\max} \sim m N^{1/2}$, the natural cutoff of a power law with $\gamma = 3$ (The largest hub).

For $m = 2$, the exact formula gives $p_2 = \frac{2\cdot2\cdot3}{2\cdot3\cdot4} = \frac12$; in general $p_m = 2/(m+2)$. For $k = 10$ it gives $p_{10} = 0.009$, against $0.008$ from the continuum formula.

Two more properties follow. The distribution is stationary: it does not depend on $t$ or $N$, which is why networks of very different age and size can share it. And its prefactor grows like $m(m+1) \approx m^2$, so $p_k/2m^2$ falls on a single curve for every $m$.

In a BA network, node A arrived at $t = 100$ and node B at $t = 10{,}000$. At $t = 10^6$, about how many times more links does A have than B?

  1. 100 times
  2. 10 times
  3. 2 times
  4. The same number
Since $k_i \propto (t/t_i)^{1/2}$, the ratio is $k_A/k_B = (t_B/t_A)^{1/2} = 10$ at every time $t$.

A growing network has 5,000 links, and a newcomer arrives with $m = 3$ links. What is the probability that one particular link of the newcomer lands on a given node with 50 links?

  1. $1/N$
  2. 1%
  3. 0.5%
  4. 1.5%
The degrees add up to $2L = 10{,}000$, so $\Pi = 50/10{,}000 = 0.5\%$.

In a large BA network where each new node brings $m = 2$ links, what share of the nodes have exactly 2 links, the minimum?

  1. About half
  2. Almost none
  3. All of them
  4. About 1%
$p_2 = 1/2$: most nodes stay small, and only a few early nodes become hubs.

Why does the BA model give $\gamma = 3$ whatever the value of $m$?

  1. Because the exponent is defined to be 3
  2. Because the starting network has three nodes
  3. Because no node can have more than three links
  4. Because $m$ cancels in the growth rate, $dk_i/dt = k_i/(2t)$
More links per newcomer also means a proportionally larger total degree to compete with. Every node therefore grows with $\beta = 1/2$, and $\gamma = 1 + 1/\beta = 3$.

The BA model has $\gamma = 3$. How does its second moment $\langle k^2\rangle$ grow with the network size $N$?

  1. It stays finite
  2. Like $N$
  3. Like $N^{1/2}$
  4. Like $\ln N$
At $\gamma = 3$, $\langle k^2\rangle \sim \ln k_{\max} \sim \ln N$: the border case (The role of γ).

In a large BA network where each new node brings $m = 3$ links, what fraction of the nodes have exactly 3 links?

  1. 40%
  2. 60%
  3. 50%
  4. About $3/N$
The exact formula gives $p_m = 2/(m+2) = 2/5$.

A BA network has $N = 10^6$ nodes, and each new node arrives with $m = 2$ links. Roughly how many links does its largest hub have?

  1. 20
  2. 2,000
  3. 1,000,000
  4. 2
Node $i$ grows as $k_i(t) = m\,(t/t_i)^{1/2}$. The largest hub is the oldest node, $t_i \approx 1$, and at $t = N$ it has $k_{\max} \sim m N^{1/2} = 2 \times 1{,}000 = 2{,}000$. Here $m$ is both the number of links a new node brings and the smallest degree in the network.
