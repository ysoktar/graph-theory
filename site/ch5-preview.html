The Barabási–Albert model

The random network and the configuration model describe networks; neither explains why hubs exist. Chapter 5 proposes a mechanism with two ingredients, both absent from the random network model: networks grow, and new nodes prefer to link to well-connected nodes.

The model (Section 5.3)

  1. Growth. Start with $m_0$ linked nodes. At every time step add one new node with $m \le m_0$ links.
  2. Preferential attachment. Each link of the new node connects to an existing node $i$ with probability $$\Pi(k_i) = \frac{k_i}{\sum_j k_j}.$$

The degree distribution (Sections 5.4–5.5)

In the continuum approximation, node $i$ (arrived at time $t_i$) gains links at the rate $dk_i/dt = m\,\Pi(k_i) = k_i/(2t)$, so

$$k_i(t) = m\left(\frac{t}{t_i}\right)^{1/2}, \qquad p_k \approx 2m^2 k^{-3}.$$

The exact solution for large $t$ is $p_k = \dfrac{2m(m+1)}{k(k+1)(k+2)}$: a power law with $\gamma = 3$, independent of $m$. The largest hub grows like $k_{\max} \sim m N^{1/2}$, the natural cutoff for $\gamma = 3$.

Both ingredients are needed (Section 5.6). Growth without preference (uniform attachment) gives an exponential degree distribution. Preference without growth (a fixed set of nodes that keep adding links preferentially) is not stationary: the network eventually fills up and becomes complete.

The BA model always gives $\gamma = 3$, yet the book's networks have exponents from 1.9 to 4.8. Its degree correlations and clustering are also far below the real values. What could the model be missing?

Nodes differ in intrinsic attractiveness (fitness, the topic of Chapter 6), links can be added between existing nodes or removed, preferential attachment can be sub- or superlinear ($\Pi(k) \sim k^\alpha$ with $\alpha \ne 1$, which breaks the power law), and nodes may age. Each of these changes the exponent or the shape of the tail. The model's clustering vanishes as $\langle C\rangle \sim (\ln N)^2/N$, more slowly than a random network's $1/N$ but still to zero.

In a BA network, node A arrived at $t = 100$ and node B at $t = 10{,}000$. At $t = 10^6$, about how many times more links does A have than B?

  1. 100 times
  2. 10 times
  3. 2 times
  4. The same number
$k_i \propto (t/t_i)^{1/2}$, so $k_A/k_B = (t_B/t_A)^{1/2} = (100)^{1/2} = 10$, whatever $t$ is. In the BA model the head start never wears off.
