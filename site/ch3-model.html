The random network model

To know which features of a real network are surprising, we need a baseline: a network in which links are placed completely at random. This null model is the subject of Chapter 3.

There are two closely related definitions:

  • $G(N, L)$: $N$ labelled nodes are connected by exactly $L$ links placed at random. This is the definition Paul Erdős and Alfréd Rényi used in their 1959–1968 papers.
  • $G(N, p)$: each of the $N(N-1)/2$ pairs of nodes is linked independently with probability $p$. This version was introduced by Edgar Gilbert, also in 1959.

Both are commonly called "Erdős–Rényi networks". $G(N,p)$ is easier to calculate with, and it is the one the book (and this site) uses. Its number of links is not fixed but random.

Building one, pair by pair

Every realisation is different

Run the procedure again with the same $N$ and $p$ and you get a different network, with a different number of links. A random network model does not describe one network but an ensemble of them, each with a probability.

The number of links is a random variable (Section 3.3)

Each of the $L_{\max} = N(N-1)/2$ pairs is a coin flip that comes up "link" with probability $p$, so $L$ follows a binomial distribution:

$$P(L) = \binom{L_{\max}}{L}\, p^{L} (1-p)^{L_{\max}-L}, \qquad \langle L\rangle = p\,\frac{N(N-1)}{2}, \qquad \sigma_L = \sqrt{L_{\max}\,p\,(1-p)}.$$

The average degree follows: $\langle k\rangle = 2\langle L\rangle/N = p(N-1)$.

The simulated histogram follows the binomial curve. Its width $\sigma_L$ grows only like $\sqrt{L_{\max}}$, so relative to $\langle L\rangle$ the fluctuations shrink as the network grows ($\sigma_L/\langle L\rangle \approx 1/\sqrt{\langle L\rangle}$ for small $p$). Large random networks of the same $N$ and $p$ are all nearly alike.

A random network has $N = 1{,}000$ nodes and $p = 0.01$. What is its average degree?

  1. 0.01
  2. 1
  3. about 10
  4. about 5,000
$\langle k\rangle = p(N-1) = 0.01 \times 999 \approx 10$. Its expected number of links is $p\,N(N-1)/2 \approx 4{,}995$.
