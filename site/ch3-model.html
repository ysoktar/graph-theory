The random network model

Is a hub with 279 links surprising? Is a clustering coefficient of 0.6 a lot? We cannot answer either question until we know what a network looks like when its links are placed purely by chance. Chapter 3 builds that reference.

  • A null model is a network in which every mechanism except chance has been left out.
  • If the data match it, no special mechanism is needed to explain them. If they deviate, something non-random shaped the network.
  • Each of the following pages predicts one Part I quantity for the random network and then compares it with the data.

Two ways to place links at random

  • $G(N, L)$ (Erdős–Rényi, 1959): choose exactly $L$ of the node pairs uniformly at random and link them.
  • $G(N, p)$ (Gilbert, 1959): link each pair independently with probability $p$. A probability is a number between 0 and 1; $p = 0.2$ means "in 20% of cases".

Both are called Erdős–Rényi networks, and for large $N$ they behave alike. $G(N,p)$ is easier to calculate with because its pairs are independent; $G(N,L)$ is handy when a random counterpart must have exactly the data's number of links.

Building one, pair by pair

The figure follows the $G(N,p)$ recipe literally: it draws one random number for each pair and adds the link if the number is below $p$.

Every realisation is different

Each run of the recipe produces a different network, called a realisation. The model therefore describes an ensemble, the set of all networks the recipe can produce, and its predictions are statements about a typical member of that set.

How many links? (Section 3.3)

  1. There are $L_{\max} = N(N-1)/2$ pairs: each node can pair with $N-1$ others, and this counts every pair twice.
  2. Each pair becomes a link with probability $p$, independently of the others.
  3. The number of successes in $L_{\max}$ independent trials follows the binomial distribution:
$$P(L) = \binom{L_{\max}}{L}\, p^{L} (1-p)^{L_{\max}-L}$$
$P(L)$
probability of exactly $L$ links
$L_{\max}$
number of node pairs, $N(N-1)/2$
$\binom{L_{\max}}{L}$
"$L_{\max}$ choose $L$": the number of ways to pick which pairs are linked, $\frac{L_{\max}!}{L!\,(L_{\max}-L)!}$
$p^{L}$
probability that those $L$ pairs are linked
$(1-p)^{L_{\max}-L}$
probability that all other pairs are not
$$\langle L\rangle = p\,\frac{N(N-1)}{2}, \qquad \sigma_L = \sqrt{L_{\max}\, p\,(1-p)}, \qquad \langle k\rangle = \frac{2\langle L\rangle}{N} = p\,(N-1).$$
$\langle L\rangle$
expected value of $L$, i.e. its average over many realisations
$\sigma_L$
standard deviation, the typical distance of $L$ from $\langle L\rangle$
$\langle k\rangle$
average degree; it equals $2L/N$ because each link has two ends (handshaking lemma)

For $N = 200$ and $p = 0.05$: $L_{\max} = 19{,}900$, $\langle L\rangle = 995$, $\sigma_L = \sqrt{19{,}900 \times 0.05 \times 0.95} \approx 30.7$ and $\langle k\rangle = 9.95$. A typical realisation has between 935 and 1,055 links ($\pm 2\sigma_L$).

For small $p$ the relative fluctuation is $\sigma_L/\langle L\rangle \approx 1/\sqrt{\langle L\rangle}$. It is 3% for 995 links and 0.45% for 50,000 links ($N = 10^4$, $\langle k\rangle = 10$). Large realisations are therefore nearly identical, and a single one can stand in for the whole ensemble.

A random counterpart of a real network

A random counterpart has the same $N$ and $L$ as the real network, with the links placed at random. For the collaboration network ($N = 23{,}133$, $L = 93{,}439$, $\langle k\rangle = 8.08$) this gives

$$p = \frac{\langle k\rangle}{N-1} = \frac{2L}{N(N-1)} = \frac{L}{L_{\max}} \approx 3.5\times10^{-4}.$$

Every random-network value quoted for a real network on the following pages refers to such a counterpart.

  • The model predicts the Part I descriptors (degree, components, distances, clustering) from $N$ and $p$ alone.
  • Next pages: degrees are Poisson, a giant component appears at $\langle k\rangle = 1$, distances grow like $\ln N$, and clustering equals $p$. The summary holds them against the data.
  • Later models extend it: the configuration model keeps the real degrees, and the Barabási–Albert model adds growth and preferential attachment.

A random network has $N = 1{,}000$ nodes and link probability $p = 0.01$. What is its average degree?

  1. 0.01
  2. 1
  3. about 10
  4. about 5,000
$\langle k\rangle = p(N-1) = 0.01 \times 999 \approx 10$.

How many links do you expect in a random network with $N = 1{,}000$ and $p = 0.01$?

  1. about 10
  2. about 4,995
  3. about 9,990
  4. about 1,000,000
$\langle L\rangle = p\,N(N-1)/2 = 0.01 \times 499{,}500 = 4{,}995$, which is also $N\langle k\rangle/2$.

You generate two realisations of a random network with $N = 5{,}000$ and $p = 0.002$. What should you expect?

  1. Two identical networks
  2. Two different networks with exactly the same number of links
  3. Two different networks whose statistics are nearly equal
  4. Two different networks with unrelated statistics
Here $\langle L\rangle \approx 24{,}995$ and $\sigma_L \approx 158$, so the two link counts differ by less than 1%.

You want a random counterpart of the US power grid, which has $N = 4{,}941$ nodes and $L = 6{,}594$ links. Which $p$ should you use?

  1. $L/N \approx 1.33$
  2. $2L/[N(N-1)] \approx 5.4\times10^{-4}$
  3. $0.5$
  4. $1/N \approx 2.0\times10^{-4}$
$p = L/L_{\max} \approx 5.4\times10^{-4}$, so $\langle k\rangle = p(N-1) = 2.67$, the grid's own average degree.

Random network A has $\langle L\rangle = 100$ links and random network B has $\langle L\rangle = 10{,}000$, both with small $p$. How large is the relative fluctuation $\sigma_L/\langle L\rangle$ of their link counts?

  1. 10% for both
  2. 1% for A, 10% for B
  3. 1% for A, 0.01% for B
  4. 10% for A, 1% for B
$\sigma_L/\langle L\rangle \approx 1/\sqrt{\langle L\rangle}$, which gives $1/\sqrt{100} = 10\%$ and $1/\sqrt{10^4} = 1\%$.

In a random network with $N = 3$ nodes and $p = 0.5$, what is the probability that a realisation has no links at all?

  1. $1/8$
  2. 0
  3. $1/2$
  4. $1/4$
There are $L_{\max} = 3$ pairs, so $P(0) = (1-p)^3 = 0.125$.

You compare $G(N, L)$ with $G(N, p)$, choosing $p$ so that $\langle L\rangle = L$. Which statement is true?

  1. They are the same model.
  2. $G(N,p)$ has more links on average.
  3. The pairs in $G(N,L)$ are independent.
  4. $L$ is fixed in $G(N,L)$ and fluctuates by about $\sigma_L$ in $G(N,p)$; for large $N$ their statistics agree.
The relative fluctuations, about $1/\sqrt{\langle L\rangle}$, vanish for large networks, so the two models become equivalent.
