The random network model

Is a hub with 279 links surprising? Is a clustering coefficient of 0.6 a lot? Neither question has an answer until we know what a network looks like when links are placed purely by chance. Chapter 3 builds that reference.

  • Null model: a network with every mechanism left out except chance.
  • Data match it → no mechanism needed. Data deviate → something non-random shaped the network.
  • Each later page predicts one Part I quantity for it, then compares with the data.

Two ways to place links at random

  • $G(N, L)$ (Erdős–Rényi, 1959): link exactly $L$ pairs, chosen uniformly at random.
  • $G(N, p)$ (Gilbert, 1959): link each pair independently with probability $p$ (a number in $[0,1]$; $p = 0.2$ means "in 20% of cases").

Both are called Erdős–Rényi networks and agree for large $N$. $G(N,p)$ is easier to calculate with (pairs are independent); $G(N,L)$ gives a random counterpart with exactly the data's $L$.

The figure runs the $G(N,p)$ recipe: one random number per pair, link if it is below $p$.

Every realisation is different

Each run gives a different network, a realisation. The model describes the ensemble of all possible realisations; its predictions are about typical members.

How many links? (Section 3.3)

  1. Pairs: $L_{\max} = N(N-1)/2$ (each node pairs with $N-1$ others; each pair counted twice).
  2. Each pair is a link with probability $p$, independently.
  3. Number of successes in $L_{\max}$ independent trials → binomial distribution:
$$P(L) = \binom{L_{\max}}{L}\, p^{L} (1-p)^{L_{\max}-L}$$
$P(L)$
probability of exactly $L$ links
$L_{\max}$
number of node pairs, $N(N-1)/2$
$\binom{L_{\max}}{L}$
"$L_{\max}$ choose $L$": ways to pick which pairs are linked, $\frac{L_{\max}!}{L!\,(L_{\max}-L)!}$
$p^{L}$
probability that those $L$ pairs are linked
$(1-p)^{L_{\max}-L}$
probability that the rest are not
$$\langle L\rangle = p\,\frac{N(N-1)}{2}, \qquad \sigma_L = \sqrt{L_{\max}\, p\,(1-p)}, \qquad \langle k\rangle = \frac{2\langle L\rangle}{N} = p\,(N-1).$$
$\langle L\rangle$
expected value (average over realisations) of $L$
$\sigma_L$
standard deviation: typical deviation of $L$ from $\langle L\rangle$
$\langle k\rangle$
average degree; $2L/N$ because each link has two ends (handshaking lemma)

$N = 200$, $p = 0.05$: $L_{\max} = 19{,}900$, $\langle L\rangle = 995$, $\sigma_L = \sqrt{19{,}900 \times 0.05 \times 0.95} \approx 30.7$, $\langle k\rangle = 9.95$. Typical range ($\pm 2\sigma_L$): 935–1,055 links.

For small $p$, $\sigma_L/\langle L\rangle \approx 1/\sqrt{\langle L\rangle}$: 3% for 995 links, 0.45% for 50,000 ($N = 10^4$, $\langle k\rangle = 10$). Large realisations are nearly identical, so one stands in for the ensemble.

A random counterpart of a real network

Same $N$ and $L$, links placed at random. For the collaboration network ($N = 23{,}133$, $L = 93{,}439$, $\langle k\rangle = 8.08$):

$$p = \frac{\langle k\rangle}{N-1} = \frac{2L}{N(N-1)} = \frac{L}{L_{\max}} \approx 3.5\times10^{-4}.$$

Every random-network value quoted for a real network on the following pages refers to such a counterpart.

$N = 1{,}000$, $p = 0.01$. Average degree?

  1. 0.01
  2. 1
  3. about 10
  4. about 5,000
$\langle k\rangle = p(N-1) = 0.01 \times 999 \approx 10$.

Expected number of links in $G(1{,}000,\ 0.01)$?

  1. about 10
  2. about 4,995
  3. about 9,990
  4. about 1,000,000
$\langle L\rangle = p\,N(N-1)/2 = 0.01 \times 499{,}500 = 4{,}995 = N\langle k\rangle/2$.

Two realisations of $G(5{,}000,\ 0.002)$. What do you expect?

  1. Identical networks
  2. Different networks, exactly equal L
  3. Different networks with nearly equal statistics
  4. Different networks, unrelated statistics
$\langle L\rangle \approx 24{,}995$, $\sigma_L \approx 158$: link counts differ by under 1%.

Random counterpart of the US power grid ($N = 4{,}941$, $L = 6{,}594$): which $p$?

  1. $L/N \approx 1.33$
  2. $2L/[N(N-1)] \approx 5.4\times10^{-4}$
  3. $0.5$
  4. $1/N \approx 2.0\times10^{-4}$
$p = L/L_{\max} \approx 5.4\times10^{-4}$, so $\langle k\rangle = p(N-1) = 2.67$, the grid's own value.

Random networks A ($\langle L\rangle = 100$) and B ($\langle L\rangle = 10{,}000$), small $p$. Relative fluctuation $\sigma_L/\langle L\rangle$?

  1. 10% for both
  2. A 1%, B 10%
  3. A 1%, B 0.01%
  4. A 10%, B 1%
$\sigma_L/\langle L\rangle \approx 1/\sqrt{\langle L\rangle}$: $1/\sqrt{100} = 10\%$, $1/\sqrt{10^4} = 1\%$.

$G(N = 3,\ p = 0.5)$. Probability that a realisation has no links?

  1. $1/8$
  2. 0
  3. $1/2$
  4. $1/4$
$L_{\max} = 3$, so $P(0) = (1-p)^3 = 0.125$.

$G(N, L)$ and $G(N, p)$ with $p$ chosen so that $\langle L\rangle = L$. Which is true?

  1. They are the same model
  2. $G(N,p)$ has more links on average
  3. $G(N,L)$ has independent pairs
  4. $L$ is fixed in one, fluctuates by $\sigma_L$ in the other; for large $N$ their statistics agree
Relative fluctuations $\sim 1/\sqrt{\langle L\rangle}$ vanish for large networks, so the two models become equivalent.
