The adjacency matrix

To compute anything about a network, we must record which pairs of nodes are linked. The adjacency matrix does this in a table of 0s and 1s, and turns network questions (degrees, common neighbours, triangles) into arithmetic.

Definition

For a network of $N$ nodes, $A$ is an $N \times N$ table:

$$A_{ij} = \begin{cases} 1 & \text{if nodes } i \text{ and } j \text{ are linked,}\\ 0 & \text{otherwise.}\end{cases}$$
$A_{ij}$
the entry in row $i$ and column $j$
$A_{ii}$
a diagonal entry; it is 0 when there are no self-loops (links from a node to itself)

In an undirected network $A_{ij} = A_{ji}$, so $A$ is symmetric and contains $2L$ ones. The degrees and the number of links follow from it:

$$k_i = \sum_{j=1}^{N} A_{ij}, \qquad L = \frac{1}{2}\sum_{i,j=1}^{N} A_{ij}.$$
$\sum_j A_{ij}$
the sum of row $i$, which is the degree $k_i$
$\tfrac12 \sum_{i,j}$
the sum of all entries, halved, because each link appears twice: as $A_{ij}$ and as $A_{ji}$

For a directed network the book's convention is $A_{ij} = 1$ for a link from $j$ to $i$. Then the row sums are in-degrees, the column sums are out-degrees, and $A$ is usually not symmetric. Many software packages use the opposite convention, so check which one you are reading.

The links 1–2, 1–3, 2–3 and 3–4 give $A = \begin{pmatrix} 0&1&1&0\\ 1&0&1&0\\ 1&1&0&1\\ 0&0&1&0 \end{pmatrix}$. The row sums are 2, 2, 3 and 1, and they add up to $8 = 2L$.

Edit a network through its matrix

  • In an undirected network, clicking $A_{ij}$ also sets $A_{ji}$, the diagonal stays empty, and the row sums are the degrees.
  • In a directed network one entry is one arrow. The row sums are in-degrees and the column sums out-degrees, and both add up to $L$.

The karate club as a matrix

Walks and triangles from powers of $A$

A walk of length $n$ is a sequence of $n$ consecutive links. Unlike a path, a walk may visit a node more than once. The product $A^2 = A \cdot A$ counts the walks of length 2:

$$(A^2)_{ij} = \sum_{m=1}^{N} A_{im}A_{mj}, \qquad (A^n)_{ij} = \#\text{walks of length } n \text{ from } i \text{ to } j.$$
$A_{im}A_{mj}$
1 if $i$–$m$ and $m$–$j$ are both links, which gives one walk $i \to m \to j$
$(A^2)_{ij}$
for $i \ne j$, the number of common neighbours of $i$ and $j$
$A^n$
$A$ multiplied by itself $n$ times

The distance $d_{ij}$ is the smallest $n$ for which $(A^n)_{ij} > 0$. A triangle is a closed walk of length 3, and the trace counts each triangle 6 times (3 starting nodes × 2 directions):

$$\#\text{triangles} = \frac{1}{6}\,\mathrm{Tr}\, A^3, \qquad \bigl(A^3\bigr)_{ii} = 2\times(\text{triangles through } i).$$
$\mathrm{Tr}\,A^3$
the trace: the sum of the diagonal entries of $A^3$
$(A^3)_{ii}$
the number of closed 3-step walks that start and end at $i$

In the example above, $A_{14} = 0$ but $(A^2)_{14} = 1$ (through node 3), so $d_{14} = 2$. $\mathrm{Tr}\,A^3 = 2+2+2+0 = 6$, which means one triangle.

In the karate club, $A_{0,33} = 0$ and $(A^2)_{0,33} = 4$, so $d = 2$. $\mathrm{Tr}\,A^3 = 270$, which means 45 triangles.

  • Network questions become linear algebra, which computers do fast.
  • $A^2$ counts common neighbours, the basis of friend recommendation and link prediction.
  • $A^3$ counts triangles, which give the clustering coefficient.
  • The eigenvectors of $A$ rank nodes by importance and find communities.

The adjacency matrix of the karate club has $34^2 = 1{,}156$ entries, of which 156 are non-zero. What fraction would be non-zero for the collaboration network, with $N = 23{,}133$ and $L = 93{,}439$? What does that suggest about how to store large networks?

$2L/N^2 = 186{,}878 / 535{,}135{,}689 \approx 0.035\%$. The matrix is almost all zeros, so real networks are stored as edge lists or sparse matrices (next page).
  • Contains the degrees (row sums) and the handshaking identity (all entries add up to $2L$).
  • Is mostly zeros for real networks: see sparsity.
  • Gives distances (the first $n$ with $(A^n)_{ij} > 0$), components (diagonal blocks when the nodes are ordered by component) and clustering (triangles).
  • Random model: G(N, p) fills each $A_{ij}$ with $i < j$ with a 1, independently, with probability $p$.

In an undirected network, what is $(A^2)_{ii}$?

  1. The degree $k_i$.
  2. 0, because there are no self-loops.
  3. The number of triangles through $i$.
  4. $2k_i$.
$(A^2)_{ii} = \sum_m A_{im}^2 = k_i$: there is one out-and-back walk for each neighbour.

In the karate club, $A_{0,33} = 0$ and $(A^2)_{0,33} = 4$. What is the distance between members 0 and 33?

  1. 1
  2. 2
  3. 4
  4. It cannot be read from $A$.
There is no walk of length 1 and there are four of length 2, so $d_{0,33} = 2$.

The adjacency matrix of an undirected network without self-loops contains 40 ones. How many links does the network have?

  1. 40
  2. 20
  3. 80
  4. 10
Each link fills two cells, so $L = 40/2 = 20$.

With the book's convention ($A_{ij} = 1$ for a link from $j$ to $i$), what is the sum of row $i$?

  1. The out-degree of $i$.
  2. The in-degree of $i$.
  3. The total degree of $i$.
  4. The number of links $L$.
Row $i$ has a 1 for every link $j \to i$, that is, for every link arriving at $i$.

In the karate club, $\mathrm{Tr}\,A^3 = 270$. How many triangles does it contain?

  1. 270
  2. 90
  3. 45
  4. 135
Each triangle gives 3 starting nodes × 2 directions = 6 closed walks, so there are $270/6 = 45$ triangles.

A network has the links 1–2, 1–3, 2–3 and 3–4. What is $(A^2)_{12}$?

  1. 0, because 1 and 2 are linked directly.
  2. 2
  3. 3
  4. 1
The only walk $1 \to m \to 2$ goes through $m = 3$, so 1 and 2 have one common neighbour.

When is the adjacency matrix of a directed network symmetric?

  1. Always.
  2. Never.
  3. When there are no self-loops.
  4. When every link has a reverse link.
$A_{ij} = A_{ji}$ for all pairs means that every link $j \to i$ comes with a link $i \to j$: the network is effectively undirected.
