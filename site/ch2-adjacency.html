The adjacency matrix

A complete description of a network has to record which pairs of nodes are linked. One way is a list of links; for mathematics the natural object is the adjacency matrix.

For a network of $N$ nodes, $A$ has $N$ rows and $N$ columns, with

$$A_{ij} = \begin{cases} 1 & \text{if nodes } i \text{ and } j \text{ are linked,}\\ 0 & \text{otherwise.}\end{cases}$$

In an undirected network each link appears twice ($A_{ij} = A_{ji} = 1$), so $A$ is symmetric and has $2L$ non-zero entries. The degrees and the number of links follow directly from it:

$$k_i = \sum_{j=1}^{N} A_{ij}, \qquad L = \frac{1}{2}\sum_{i,j=1}^{N} A_{ij}.$$

For a directed network the book's convention is $A_{ij} = 1$ if a link points from $j$ to $i$. Then row sums give in-degrees and column sums give out-degrees, $k_i^{\text{in}} = \sum_j A_{ij}$ and $k_j^{\text{out}} = \sum_i A_{ij}$, and $A$ is generally not symmetric.

Edit a network through its matrix

  • In undirected mode, clicking $A_{ij}$ also sets $A_{ji}$: the matrix stays symmetric, the diagonal stays empty (no self-loops), and each row sum is the node's degree.
  • In directed mode a single entry is one arrow. Row sums become in-degrees and column sums out-degrees, and both add up to $L$.

The karate club as a matrix

The same 34 members and 78 links as before, now as a $34\times 34$ matrix. The order of the rows is arbitrary (any relabelling of the nodes is the same network), yet a good order can reveal structure.

Sorted by faction, two dense blocks appear on the diagonal: most links stay within a faction. This is a first glimpse of community structure (Chapter 9), visible directly in $A$. In random order the same matrix looks like noise.

Linear algebra on $A$: walks and triangles

Multiplying the matrix by itself counts walks. $(A^2)_{ij} = \sum_k A_{ik}A_{kj}$ adds 1 for every node $k$ linked to both $i$ and $j$. For $i \ne j$ that is the number of common neighbours: walks $i \to k \to j$. In general

$$(A^n)_{ij} = \text{number of walks of length } n \text{ from } i \text{ to } j,$$

and the distance $d_{ij}$ is the smallest $n$ with $(A^n)_{ij} > 0$. A triangle $i \to j \to k \to i$ is a closed walk of length 3. Each triangle is counted six times in the trace (three starting nodes, two directions), so

$$\#\text{triangles} = \frac{1}{6}\,\mathrm{Tr}\, A^3, \qquad \bigl(A^3\bigr)_{ii} = 2\times(\text{triangles through } i).$$

In an undirected network, what is $(A^2)_{ii}$?

  1. The degree $k_i$
  2. Zero, because there are no self-loops
  3. The number of triangles through $i$
  4. Twice the degree
$(A^2)_{ii} = \sum_k A_{ik}A_{ki} = \sum_k A_{ik} = k_i$: one walk $i \to k \to i$ for each neighbour $k$.

The adjacency matrix of the karate club has $34^2 = 1{,}156$ entries, of which 156 are non-zero. What fraction would be non-zero for the collaboration network with $N = 23{,}133$ and $L = 93{,}439$? What does that suggest about how to store large networks?

$2L/N^2 = 186{,}878 / 535{,}135{,}689 \approx 0.035\%$. Almost the whole matrix is zeros, which is why real networks are stored as edge lists or sparse matrices. That is the topic of the next page.
