The adjacency matrix

To compute anything we must record which pairs are linked. The adjacency matrix does this in a table of 0s and 1s, and turns network questions (degrees, common neighbours, triangles) into arithmetic.

Definition

For $N$ nodes, $A$ is an $N \times N$ table:

$$A_{ij} = \begin{cases} 1 & \text{if nodes } i \text{ and } j \text{ are linked,}\\ 0 & \text{otherwise.}\end{cases}$$
$A_{ij}$
entry in row $i$, column $j$
$A_{ii}$
diagonal; 0 without self-loops

Undirected: $A_{ij} = A_{ji}$, so $A$ is symmetric and has $2L$ ones. Degrees and links follow:

$$k_i = \sum_{j=1}^{N} A_{ij}, \qquad L = \frac{1}{2}\sum_{i,j=1}^{N} A_{ij}.$$
$\sum_j A_{ij}$
row sum = degree $k_i$
$\tfrac12 \sum_{i,j}$
all entries, halved: each link appears as $A_{ij}$ and $A_{ji}$

Directed (book's convention): $A_{ij} = 1$ for a link from $j$ to $i$. Row sums are in-degrees, column sums out-degrees; $A$ is generally not symmetric. Software often uses the opposite convention.

Links 1–2, 1–3, 2–3, 3–4: $A = \begin{pmatrix} 0&1&1&0\\ 1&0&1&0\\ 1&1&0&1\\ 0&0&1&0 \end{pmatrix}$, row sums 2, 2, 3, 1; total $8 = 2L$.

Edit a network through its matrix

  • Undirected: clicking $A_{ij}$ also sets $A_{ji}$; the diagonal stays empty; row sums are degrees.
  • Directed: one entry is one arrow; row sums are in-degrees, column sums out-degrees, both totalling $L$.

Walks and triangles from powers of $A$

A walk of length $n$ is $n$ consecutive links; it may revisit nodes (a path may not). The product $A^2 = A \cdot A$ counts walks of length 2:

$$(A^2)_{ij} = \sum_{m=1}^{N} A_{im}A_{mj}, \qquad (A^n)_{ij} = \#\text{walks of length } n \text{ from } i \text{ to } j.$$
$A_{im}A_{mj}$
1 if $i$–$m$ and $m$–$j$ are both links: one walk $i \to m \to j$
$(A^2)_{ij}$
for $i \ne j$: number of common neighbours
$A^n$
$A$ multiplied by itself $n$ times

The distance $d_{ij}$ is the smallest $n$ with $(A^n)_{ij} > 0$. A triangle is a closed walk of length 3, counted 6 times in the trace (3 starting nodes × 2 directions):

$$\#\text{triangles} = \frac{1}{6}\,\mathrm{Tr}\, A^3, \qquad \bigl(A^3\bigr)_{ii} = 2\times(\text{triangles through } i).$$
$\mathrm{Tr}\,A^3$
trace: sum of the diagonal of $A^3$
$(A^3)_{ii}$
closed 3-step walks from $i$

Example above: $A_{14} = 0$, $(A^2)_{14} = 1$ (via 3), so $d_{14} = 2$; $\mathrm{Tr}\,A^3 = 2+2+2+0 = 6$ → 1 triangle.

Karate: $A_{0,33} = 0$, $(A^2)_{0,33} = 4$ → $d = 2$; $\mathrm{Tr}\,A^3 = 270$ → 45 triangles.

  • Network questions become fast linear algebra.
  • $A^2$ (common neighbours) underlies friend recommendation and link prediction.
  • $A^3$ (triangles) gives clustering; eigenvectors of $A$ rank nodes and find communities.

The adjacency matrix of the karate club has $34^2 = 1{,}156$ entries, of which 156 are non-zero. What fraction would be non-zero for the collaboration network with $N = 23{,}133$ and $L = 93{,}439$? What does that suggest about how to store large networks?

$2L/N^2 = 186{,}878 / 535{,}135{,}689 \approx 0.035\%$. The matrix is almost all zeros, so real networks are stored as edge lists or sparse matrices (next page).
  • Encodes degree (row sums) and handshaking (sum of all entries).
  • Mostly zeros in real networks: sparsity.
  • Gives distances (first $n$ with $(A^n)_{ij} > 0$), components (diagonal blocks), clustering (triangles).
  • Random model: G(N, p) fills each $A_{ij}$, $i < j$, with 1 independently with probability $p$.

Undirected network: what is $(A^2)_{ii}$?

  1. The degree $k_i$
  2. 0, as there are no self-loops
  3. Triangles through $i$
  4. $2k_i$
$(A^2)_{ii} = \sum_m A_{im}^2 = k_i$: one out-and-back walk per neighbour.

Karate: $A_{0,33} = 0$, $(A^2)_{0,33} = 4$. Distance between 0 and 33?

  1. 1
  2. 2
  3. 4
  4. Not readable from $A$
No 1-step walk, four 2-step walks, so $d_{0,33} = 2$.

An undirected matrix without self-loops has 40 ones. How many links?

  1. 40
  2. 20
  3. 80
  4. 10
$L = 40/2 = 20$.

Book convention ($A_{ij} = 1$ for $j \to i$): what is the sum of row $i$?

  1. Out-degree of $i$
  2. In-degree of $i$
  3. Total degree
  4. $L$
Row $i$ has a 1 for every link $j \to i$, i.e. every link arriving at $i$.

Karate: $\mathrm{Tr}\,A^3 = 270$. How many triangles?

  1. 270
  2. 90
  3. 45
  4. 135
3 starts × 2 directions = 6 walks per triangle: $270/6 = 45$.
