How the topics connect

Each box is a page; an arrow means "leads to". Dashed arrows: a null model, a network wired at random under constraints, predicts what randomness alone would give, and the data are compared with it.

  • Degrees: the random model predicts Poisson degrees; real networks have heavy tails, described by power laws, which create hubs; hubs decide robustness and spreading.
  • Distances: short paths are generic (small worlds); hubs make them shorter still (ultra-small).
  • Clustering: far above the random value; Watts–Strogatz adds it while keeping paths short.
  • Null models: G(N, L) keeps only $N$ and $L$; the configuration model also keeps every degree; degree-preserving randomization does so by rewiring the real links.

Questions

Each page ends its sections with Check yourself questions. A wrong choice tells you why it is wrong; the right one explains the answer. The same questions feed the practice sets of the midterm and final study guides.

A network has $N = 10$ nodes and $L = 15$ links. What is its average degree $\langle k\rangle$?

  1. 1.5
  2. 0.67
  3. 3
  4. 30
$\langle k\rangle = 2L/N = 2 \cdot 15 / 10 = 3$.

Everything runs on your machine. This is a static website. Simulations, fits and graph algorithms run as JavaScript in your browser, and nothing is sent anywhere. The real-network data are compact summaries (degree histograms, fits, clustering, distances) precomputed once from the book's edge lists. For six of the eight networks the full edge lists are included, so the site can also analyse those networks live.
