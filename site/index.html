The plan

Parts I–IV follow the class notebook From Graphs to Hubs section by section, and go further wherever an interactive picture helps. Part V covers the rest of the course syllabus: the Barabási–Albert model, evolving networks, degree correlations, robustness, graph machine learning and node embeddings, plus communities and spreading. Each part answers one question.

How to read the figures

The colour conventions are the notebook's, used the same way throughout:

real data (other series: orange, then aqua) random network theory, a formula
  • Hover any chart for exact values; every chart also has a Data table underneath.
  • Network views can be dragged, panned and zoomed (click inside first, then scroll or pinch). Re-layout shakes the layout and Fit zooms back to the whole network.
  • Boxes marked Look for say what a figure should show you. Discuss boxes are the notebook's discussion questions, with hints. Check yourself questions give instant feedback.
  • Heavier simulations run in a background thread. Their figures fill in as results arrive.

Everything runs on your machine. This is a static website. Simulations, fits and graph algorithms run as JavaScript in your browser, and nothing is sent anywhere. The real-network data are compact summaries (degree histograms, fits, clustering, distances) precomputed once from the book's edge lists. For six of the eight networks the full edge lists are included, so the site can also analyse those networks live.

The class notebook was re-checked number by number while this site was built. Nearly everything holds up. The few statements that needed a correction or a caveat are listed on the Notebook check page and discussed where they come up.
