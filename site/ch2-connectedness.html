Connectedness

A phone is useless if no path leads from it to the phone it calls. Whether a network holds together, and which single links or nodes it depends on, is a question about paths.

  • A network is connected when a path joins every pair of nodes.
  • A component is a largest set of nodes that are all joined by paths. No path runs from one component to another.
  • A bridge is a link whose removal splits a component in two.
  • An articulation point (or cut vertex) is a node whose removal splits a component.

If the nodes are numbered component by component, the adjacency matrix $A$ becomes block diagonal: all its non-zero entries lie in square blocks along the diagonal.

The karate club is a single component. Its only bridge is the link 0–11 (member 11 has $k_{11} = 1$), and its only articulation point is node 0.

Cut it apart

  • Cutting a bridge (a thick dark line) splits a component; for any other link there is an alternative path.
  • Articulation points (ringed) are single points of failure between groups of nodes.
  • When the nodes are ordered by component, the matrix is block diagonal.

The giant component

Large real networks are rarely connected, but one giant component holds most of the nodes, and the rest form a "dust" of small components.

The collaboration network has 567 components. The giant component holds 21,363 scientists (92%), and the second-largest only 21. Evolution shows that a random network with $\langle k\rangle > 1$ looks exactly like this.

How much damage does it take?

Remove links at random and follow the size of the largest component (a preview of Robustness). The dashed lines mark the Molloy–Reed threshold: if fewer links than this are kept, a random network with the same degrees falls apart.

$$p_c = \frac{\langle k\rangle}{\langle k^2\rangle - \langle k\rangle}.$$
$p_c$
the critical fraction of links that must be kept
$\langle k\rangle$
the average degree
$\langle k^2\rangle$
the average of the squared degrees, which is large when there are hubs

For the collaboration network, $p_c = 8.08/(178.2 - 8.08) \approx 0.048$. For the power grid, $p_c = 2.67/(10.33 - 2.67) \approx 0.35$.

With 20% of links kept, the collaboration network's largest component still holds about half the scientists. The power grid, with half its lines gone, keeps only a few percent: it fragments well above $p_c \approx 0.35$, because a lattice-like spatial network has few alternative routes.

  • Components say who can reach whom at all; a distance exists only where there is a path.
  • Bridges and articulation points locate single points of failure.
  • $p_c$ predicts, from the degrees alone, how much random damage a network survives.
  • Needed by distances: $d = \infty$ between components, so $\langle d\rangle$ uses the giant component.
  • Seen in the adjacency matrix as diagonal blocks.
  • Explained by the random model: a giant component appears at $\langle k\rangle = 1$ (Evolution).
  • Predicts robustness: hubs raise $\langle k^2\rangle$ and lower $p_c$ (Robustness, No typical degree).

Two networks have the same average degree $\langle k\rangle$, but one has hubs and therefore a larger $\langle k^2\rangle$. Which one survives more random loss of links?

  1. The one with hubs, because its $p_c$ is smaller.
  2. The one without hubs.
  3. Both equally.
  4. It cannot be told from the degrees.
A larger $\langle k^2\rangle$ lowers $p_c$: hubs keep the network together under random failure (0.048 for the collaboration network against 0.35 for the power grid).

  1. 9
  2. 7
  3. 10
  4. 3
Each component is a tree, and a tree has one link fewer than it has nodes, so $L = 10 - 3 = 7$.
