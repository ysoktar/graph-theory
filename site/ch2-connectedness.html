Connectedness

A phone is useless if there is no path from it to the phone it calls. Whether a network holds together is a question about paths.

A network is connected if there is a path between every pair of nodes. Otherwise it splits into components: maximal sets of nodes joined by paths, with no path between different components. A link whose removal disconnects the network is a bridge, and a node whose removal does so is an articulation point (or cut vertex). If the nodes are numbered component by component, the adjacency matrix becomes block diagonal: all non-zero entries fall in square blocks along the diagonal.

Cut it apart

  • Cutting a bridge (thick dark line) splits a component in two. Cutting any other link leaves the components as they are, because an alternative path exists.
  • The articulation points (ringed) are the single points of failure: every path between the two clusters runs through them.
  • The matrix, ordered by component, is block diagonal: no link joins two blocks.

The giant component

Large real networks are rarely connected, but they are far from shattered. One component, the giant component, contains most nodes. The rest form a "dust" of small components.

One giant component and a dust of tiny ones, with nothing in between: in the collaboration network the second-largest component has only 21 scientists. Chapter 3 shows that this is exactly what a random network with $\langle k\rangle > 1$ looks like.

How much damage does it take?

Remove links at random from a real network and track the largest component. This anticipates the robustness analysis of Chapter 8.

The collaboration network shrugs off the loss of most links: with only 20% of the collaborations kept, its largest component still holds about half of all scientists. The power grid is far more fragile. With half of its lines removed at random, its largest piece holds only a few percent of the nodes. It fragments well above $p_c \approx 0.35$, the threshold of a random network with the same degrees, because a lattice-like spatial network has few alternative routes. The dashed lines mark that threshold, $p_c = \langle k\rangle / (\langle k^2\rangle - \langle k\rangle)$ (the Molloy–Reed criterion): the more heterogeneous the degrees, the smaller $p_c$.

A network has $N = 100$ nodes in a single component, and every node has degree 2. Which statement is certainly true?

  1. It has a bridge
  2. It is a tree
  3. It has $L = 200$ links
  4. It is a single cycle, so removing any one link leaves it connected
Degree 2 everywhere with one component means a ring of 100 nodes and $L = N\langle k\rangle/2 = 100$ links. No link is a bridge; it takes two cuts to split it.
