Connectedness

A phone is useless if no path leads from it to the phone it calls. Whether a network holds together, and which single links or nodes it depends on, is a question about paths.

  • Connected: a path joins every pair of nodes.
  • Component: a largest set of nodes joined by paths; no path runs between components.
  • Bridge: a link whose removal splits a component.
  • Articulation point (cut vertex): a node whose removal splits a component.

Numbering the nodes component by component makes $A$ block diagonal: all non-zero entries lie in square blocks on the diagonal.

Karate: one component; its only bridge is 0–11 ($k_{11} = 1$), its only articulation point node 0.

Cut it apart

  • Cutting a bridge (thick dark line) splits a component; any other link has an alternative path.
  • Articulation points (ringed) are single points of failure between clusters.
  • Ordered by component, the matrix is block diagonal.

The giant component

Large real networks are rarely connected, but one giant component holds most nodes; the rest is a "dust" of small components.

Collaboration: 567 components; the giant holds 21,363 scientists (92%), the second-largest only 21. Evolution shows that a random network with $\langle k\rangle > 1$ looks exactly like this.

How much damage does it take?

Remove links at random and track the largest component (preview of Robustness). The dashed lines mark the Molloy–Reed threshold, below which a random network with the same degrees falls apart:

$$p_c = \frac{\langle k\rangle}{\langle k^2\rangle - \langle k\rangle}.$$
$p_c$
critical fraction of links kept
$\langle k\rangle$
average degree
$\langle k^2\rangle$
average squared degree; large when there are hubs

Collaboration: $8.08/(178.2 - 8.08) \approx 0.048$. Power grid: $2.67/(10.33 - 2.67) \approx 0.35$.

With 20% of links kept, the collaboration network's largest component still holds about half the scientists. The power grid, with half its lines gone, keeps only a few percent: it fragments well above $p_c \approx 0.35$, because a lattice-like spatial network has few alternative routes.

  • Components say who can reach whom at all; distances need a path.
  • Bridges and articulation points locate single points of failure.
  • $p_c$ predicts from degrees alone how much random damage a network survives.
  • Needed by distances: $d = \infty$ between components, so $\langle d\rangle$ uses the giant component.
  • Seen in the adjacency matrix as diagonal blocks.
  • Explained by the random model: a giant component appears at $\langle k\rangle = 1$ (Evolution).
  • Predicts robustness: hubs raise $\langle k^2\rangle$ and lower $p_c$ (Robustness, No typical degree).
