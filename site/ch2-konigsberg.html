Königsberg and the birth of graph theory

Seven bridges joined the four parts of Königsberg (today Kaliningrad). Can you walk across every bridge exactly once? In 1736 Euler showed that you cannot, and why: the answer depends only on how the land is connected.

Take the walk

Click a piece of land to start, then click bridges. Highlighted bridges are the ones you can still take.

  • Whatever route you try, you get stuck before you have used every bridge.
  • Every land mass has an odd number of bridges: 5, 3, 3 and 3.
  • Switch to Edit bridges and add or remove one bridge. Now a walk exists: it runs between the two land masses that still have an odd number of bridges.

Step 1: keep only the connections

The shapes of the land and the lengths of the bridges cannot change the answer; only which land is joined to which can. Euler drew each land mass as a point and each bridge as a line. That is a graph:

  • node: a land mass (A, B, C, D);
  • link: a bridge (a–g);
  • degree $k$: the number of links at a node. Island A has five bridges, so $k_A = 5$.
  • Replacing a system by its pattern of connections is the method of network science.
  • One argument then covers bridges, streets, power lines or friendships alike.

Step 2: count bridges in pairs

  1. A land mass you only pass through is entered by one bridge and left by another.
  2. So its bridges are used in pairs: its degree is even.
  3. Only the start and the end can have odd degree.

A connected graph has an Euler path (a walk using every link once) if and only if it has

  • 0 odd-degree nodes: the walk can start anywhere and returns to its start (an Euler circuit);
  • 2 odd-degree nodes: the walk runs from one to the other.

Königsberg has 4, so no walk exists.

A graph is connected when every node can be reached from every other (Connectedness). Euler showed that four odd nodes make the walk impossible. Hierholzer proved in 1873 that 0 or 2 odd nodes always allow one; the Show a solution button uses his method.

Add a bridge h between B and C. Then $k_B$ and $k_C$ become 4, while A (5) and D (3) stay odd. With two odd nodes a walk exists, from A to D.

Why odd nodes come in pairs

Each link has two ends, so the degrees add up to twice the number of links:

$$\sum_{i=1}^{N} k_i = 2L$$
$k_i$
degree of node $i$
$\sum_{i=1}^{N}$
sum over all nodes, $i = 1, \dots, N$
$N$
number of nodes
$L$
number of links

Königsberg: $5 + 3 + 3 + 3 = 14 = 2 \times 7$.

Since $2L$ is even, the number of nodes with odd degree is always even. Dividing both sides by $N$ gives the average degree $\langle k\rangle = 2L/N$ (next page).

  • Degree decided this problem. How degrees are distributed is the thread of the whole course (Degree).
  • Walks along links lead to paths and distances (Paths).
  • Structure decides what is possible. Robustness (Ch 8) and spreading (Ch 10) are also set largely by the degrees.

A connected network has degrees 2, 3, 4, 3, 2, 2. Does it have an Euler path?

  1. No, because it has nodes of odd degree.
  2. Yes, and it can start and end anywhere.
  3. Yes, running from one degree-3 node to the other.
  4. It cannot be decided without a drawing.
Exactly two odd nodes: the path exists and runs between them.

A city has four districts, each with exactly four bridges, and every district can be reached from every other. Can a tourist cross every bridge once and return to the hotel?

  1. No, there are too many bridges.
  2. Yes, starting from any district.
  3. Only when starting from one particular district.
  4. Only if there are more districts than bridges.
All degrees are even and the city is connected, so an Euler circuit exists from any starting point.

Which single change to the seven bridges makes the walk possible?

  1. Removing both bridges between A and B.
  2. Adding a bridge from A back to A.
  3. None: no single change helps.
  4. Removing any one bridge.
Every bridge joins two land masses of odd degree. Removing it makes both even and leaves exactly two odd nodes.

Why may Euler ignore bridge lengths and land shapes?

  1. The answer depends only on which land each bridge joins.
  2. The maps of 1736 were inaccurate.
  3. All bridges had the same length.
  4. It is an approximation.
Which walks exist is fixed by the connections alone. Keeping only connections is the founding idea of network science.

Networks and graphs (Section 2.2)

A network lists a system's components (nodes) and their direct interactions (links). Its size is given by the number of nodes $N$ and the number of links $L$. The words network, node, link and graph, vertex, edge mean the same things. A link is undirected when the relation goes both ways (a collaboration, a power line), and directed when it points from one node to another (a hyperlink, an email, a phone call). All networks here are treated as undirected and simple (no directions, self-loops or repeated links), as in the class notebook. For directed networks $u\to v$ and $v\to u$ merge into one link, so $L$ and $\langle k\rangle$ are smaller than the book's.

The same 23,133 scientists can be linked by co-authorship, by citations or by emails. Would the three networks have the same structure? Which would you study to see how ideas spread?

The link definition makes the network. Co-authorship is undirected and full of triangles (a three-author paper is a triangle); citations are directed and reach further. Always ask what a link means.
  • Covering every street once, as a postman or a snow plough must, is the Chinese postman problem, which builds on Euler's condition.
  • Genome sequencing reassembles DNA by finding an Euler path through overlapping fragments.
  • Visiting every node once (a Hamiltonian path) looks similar but has no simple test and is computationally hard.
