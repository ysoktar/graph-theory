Königsberg and the birth of graph theory

In 18th-century Königsberg, seven bridges joined the two banks of the river Pregel, an island and a peninsula. Residents wondered whether one could take a walk that crosses every bridge exactly once. Nobody managed it. In 1736 Leonhard Euler proved that nobody ever would, and graph theory was born.

Take the walk

  • However you start, you get stuck with bridges left over.
  • Look at the degrees in the graph: every land mass has an odd number of bridges (5, 3, 3, 3).
  • Switch to Edit bridges and add or remove a single bridge. Suddenly a walk exists, but only if it starts and ends at the two land masses that still have an odd number of bridges.

Euler's argument

Euler's insight was to throw away everything except which land connects to which. Distances, shapes and positions are irrelevant; only the network matters. Then the argument is almost a one-liner. On a walk that crosses every bridge once, each time you enter a land mass by one bridge you must leave it by another. Bridges at every node you merely pass through therefore come in pairs, so those nodes have even degree. Only the start and end of the walk can have odd degree.

A connected network has a walk that uses every link exactly once (an Euler path) if and only if it has either no odd-degree nodes (then the walk can return to its start) or exactly two (then the walk must run from one to the other). Königsberg's graph has four odd-degree nodes, so the walk is impossible.

This was the first proof in graph theory. It also carries the lesson that runs through this whole course: some properties of a system are determined by its network alone. Here no amount of clever walking helps; the topology forbids it.

A connected network has nodes with degrees 2, 3, 4, 3, 2, 2. Does it have an Euler path?

  1. No: it has odd-degree nodes
  2. Yes, and it can start and end anywhere
  3. Yes, starting at one degree-3 node and ending at the other
  4. We cannot tell without seeing the network
Exactly two nodes have odd degree, so an Euler path exists and must run between them. For a connected network, the degrees alone decide.

Networks and graphs (Section 2.2)

A network is a catalogue of a system's components, the nodes (or vertices), and of the direct interactions between them, the links (or edges). Two numbers describe its size: the number of nodes $N$ and the number of links $L$. Network scientists tend to say network, node and link for real systems, and graph, vertex and edge for the mathematical object, but the terms are used interchangeably.

The choice of links defines the network, and different link definitions give very different networks on the same nodes. Co-authorship captures close collaboration (and creates many triangles, because a paper with three authors is a triangle). Citations are directed and reach far more widely. Always ask what a link means before interpreting a network's structure.
