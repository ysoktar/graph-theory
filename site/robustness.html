Robustness & attacks

How many nodes can a network lose before it falls apart? It depends on which nodes: scale-free networks are very hard to break by accident and very easy to break on purpose (Chapter 8).

  • A network works only while its nodes can reach each other; we measure that by the giant component (Ch 3).
  • The theory predicts the damage needed to destroy it from the degrees alone.
  • It tells engineers which designs survive failures and which nodes to protect.

Removing nodes is percolation

Remove a fraction $f$ of nodes; at a critical fraction $f_c$ the giant component breaks up. This threshold transition is percolation: the birth of the giant component run backwards.

  • Random failures: every node equally likely.
  • Targeted attacks: highest degree first.

The Molloy–Reed criterion

A node reached along a link must offer at least one further link, or paths die out. Such a node has mean degree $\langle k^2\rangle/\langle k\rangle$ (the friendship paradox), so a giant component needs

$$\kappa = \frac{\langle k^2\rangle}{\langle k\rangle} > 2 .$$
$\kappa$
mean degree of a node reached along a random link
$\langle k\rangle$
mean degree
$\langle k^2\rangle$
mean squared degree, large with hubs (Ch 4)
$2$
one link in, at least one out

Assumes random wiring given the degrees (configuration model).

The critical fraction

  1. Remove $f$ at random: each link survives with probability $1 - f$.
  2. The moments shrink so that $\kappa_f = (1-f)\,\kappa + f$.
  3. Set $\kappa_f = 2$ and solve:
$$f_c = 1 - \frac{1}{\kappa - 1}.$$
$f_c$
fraction of random failures that destroys the giant component
  • Random network: $\kappa = \langle k\rangle + 1$, so $f_c = 1 - 1/\langle k\rangle$.
  • Scale-free, $\gamma < 3$: $\kappa \to \infty$, so $f_c \to 1$.

Internet: $\kappa = 240.1/6.34 = 37.9$ → $f_c = 1 - 1/36.9 = 97.3\%$. Random network, same $\langle k\rangle$: $84.2\%$.

The book's networks

  • Random failures: heavy-tailed networks keep a giant component far beyond the random network's threshold.
  • Attacks: the same networks collapse after a few per cent.
  • The power grid has no hubs and is fragile to both.

Robust yet fragile: a random failure almost never hits a hub; an attack removes the hubs that hold everything together.

  • Reverse of the giant-component transition: for a random network $\kappa = 2$ is $\langle k\rangle = 1$.
  • Builds on the divergent $\langle k^2\rangle$ for $\gamma < 3$.
  • Same formula as the epidemic threshold: $T_c = 1 - f_c$.
  • Modified by degree correlations: linked hubs back each other up.

You can add links but not remove hubs. How would you resist attacks without becoming fragile to failures?

Section 8.7: a bimodal degree distribution (a few hubs, many equal nodes) maximises the combined threshold. Links between medium-degree nodes add paths that bypass hubs.

Random network, $\langle k\rangle = 4$. What fraction of random failures destroys the giant component?

  1. 25%
  2. 50%
  3. 75%
  4. 100%
$f_c = 1 - 1/4 = 75\%$; the survivors have $\langle k\rangle = 1$.

$\langle k\rangle = 5$, $\langle k^2\rangle = 255$, random wiring. $f_c$?

  1. 80%
  2. 98%
  3. 51%
  4. 2%
$\kappa = 51$, $f_c = 1 - 1/50 = 98\%$.

Why does removing the top 1% of hubs do far more damage than a random 1%?

  1. More nodes are removed
  2. Hubs fail more often
  3. Small nodes hold it together
  4. Hubs dominate $\langle k^2\rangle$, so $\kappa$ collapses
Removing hubs drives $\kappa$ to 2 within a few per cent; random removal barely changes it.

The power grid ($\kappa = 3.9$) breaks well before the Molloy–Reed $f_c = 65\%$. Why?

  1. It is spatial, not randomly wired: long chains, few alternative paths
  2. It is too small
  3. Its hubs fail first
  4. Degrees are mismeasured
Molloy–Reed assumes random wiring. The grid is stretched ($\langle d\rangle = 18.8$) and splits after about a third of its nodes fail.

  4. 0%
$f_c = 1 - 1/(3 - 1) = 50\%$.
