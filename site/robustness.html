Robustness & attacks

How many nodes can a network lose before it falls apart? It depends on which nodes: scale-free networks are very hard to break by accident and very easy to break on purpose (Chapter 8).

  • A network works only while its nodes can reach each other; we measure that by the giant component (Ch 3).
  • The theory predicts the damage needed to destroy it from the degrees alone.
  • It tells engineers which designs survive failures and which nodes to protect, and why one failure can sometimes start a blackout.

Removing nodes is percolation

Percolation theory asks the same question on a lattice. Occupy each site of a square lattice with probability $p$; neighbouring occupied sites form clusters. Nothing changes gradually: below a critical value $p_c$ there are only small clusters, and at $p_c$ one cluster suddenly spans the lattice. Near $p_c$ three quantities follow power laws:

$$\langle s\rangle \sim |p - p_c|^{-\gamma_p}, \qquad P_\infty \sim (p - p_c)^{\beta_p}, \qquad \xi \sim |p - p_c|^{-\nu}.$$
$p_c$
critical occupation probability; $p_c \approx 0.593$ for sites on a square lattice
$\langle s\rangle$
average size of the finite clusters; it diverges at $p_c$
$P_\infty$
probability that a site belongs to the spanning (largest) cluster, the order parameter
$\xi$
correlation length, the typical distance inside a cluster
$\gamma_p, \beta_p, \nu$
critical exponents; in two dimensions $43/18$, $5/36$ and $4/3$. They are universal (the same on any 2-D lattice), while $p_c$ is not

Removing a fraction $f$ of the nodes is the same process run backwards, with $p = 1 - f$: at a critical fraction $f_c = 1 - p_c$ the giant component breaks up.

  • Random failures: every node is equally likely to fail.
  • Targeted attacks: nodes are removed in order of degree, largest first.

The Molloy–Reed criterion

When does a network with a given degree distribution have a giant component? Follow a path into the network: it continues only if the node it reaches has at least one more link.

  1. A random link leads to a node of degree $k$ with probability $q_k = k\,p_k/\langle k\rangle$: high-degree nodes are reached more often.
  2. The average degree of the node reached is therefore $\sum_k k\,q_k = \langle k^2\rangle/\langle k\rangle$ (the friendship paradox).
  3. One of its links is the one we arrived on. For the path to go on, at least one more is needed on average: the node must have degree 2 or more.
$$\kappa = \frac{\langle k^2\rangle}{\langle k\rangle} > 2 .$$
$\kappa$
mean degree of a node reached along a random link
$\langle k\rangle$, $\langle k^2\rangle$
mean degree and mean squared degree; $\langle k^2\rangle$ is large when there are hubs (Ch 4)
$2$
one link in, at least one out

It assumes random wiring given the degrees (the configuration model). For a random network $\langle k^2\rangle = \langle k\rangle(1 + \langle k\rangle)$, so $\kappa = 1 + \langle k\rangle$ and the criterion becomes $\langle k\rangle > 1$, the giant-component threshold of Chapter 3.

The critical fraction

Remove a fraction $f$ of the nodes at random. A surviving node of degree $k$ keeps each of its links with probability $1 - f$, so its degree becomes binomial. The moments of the new distribution are (Advanced Topic 8.C)

$$\langle k\rangle_f = (1-f)\langle k\rangle, \qquad \langle k^2\rangle_f = (1-f)^2\langle k^2\rangle + f(1-f)\langle k\rangle, \qquad \kappa_f = (1-f)\,\kappa + f .$$

The giant component disappears when $\kappa_f = 2$. Solving for $f$:

$$f_c = 1 - \frac{1}{\kappa - 1}, \qquad f_c^{ER} = 1 - \frac{1}{\langle k\rangle}\ \text{(random network)}.$$
$f_c$
fraction of random failures that destroys the giant component; it depends only on $\langle k\rangle$ and $\langle k^2\rangle$

For a power law $p_k \sim k^{-\gamma}$ starting at $k_{\min}$ (continuum approximation, Eq. 8.9):

$$f_c = \begin{cases} 1 - \dfrac{1}{\frac{\gamma-2}{3-\gamma}\,k_{\min}^{\gamma-2}\,k_{\max}^{3-\gamma} - 1} & 2 < \gamma < 3\\[3mm] 1 - \dfrac{1}{\frac{\gamma-2}{\gamma-3}\,k_{\min} - 1} & \gamma > 3 \end{cases} \qquad\Rightarrow\qquad f_c \approx 1 - \frac{C}{N^{(3-\gamma)/(\gamma-1)}}\ \ (2 < \gamma < 3).$$
$k_{\max}$
the natural cutoff $k_{\min}N^{1/(\gamma-1)}$; it grows with $N$, so $\kappa \to \infty$ and $f_c \to 1$
$C$
a constant that collects everything independent of $N$ (Eq. 8.10)

Worked example: the Internet.

  1. Given: $\langle k\rangle = 6.34$ and $\langle k^2\rangle = 240.1$ for the router map ($N = 192{,}244$).
  2. $\kappa = 240.1/6.34 = 37.9$, far above 2.
  3. $f_c = 1 - 1/(37.9 - 1) = 1 - 1/36.9 = 0.973$.
  4. A random network with the same $\langle k\rangle$: $f_c^{ER} = 1 - 1/6.34 = 0.842$.
  5. Meaning: 97% of the routers, about 187,000, must fail at random to fragment it. The hubs supply the extra robustness.

Worked example: when the network stops being special. For $\gamma = 4$ and $k_{\min} = 2$, the continuum formula gives $\kappa = \frac{2}{1}\cdot 2 = 4$ and $f_c = 1 - 1/3 = 2/3$, independent of $N$: above $\gamma = 3$ a scale-free network breaks after a finite fraction of failures, like a random one.

Choose a degree distribution

Everything above follows from two numbers, $\langle k\rangle$ and $\langle k^2\rangle$, so the shape of $p_k$ decides robustness. Compare distributions with the same average degree:

The book's networks

  • Attacks: the same networks collapse after a few per cent.
  • The power grid has no hubs and is fragile to both.

Attacks

An attack removes the hubs first. That changes the network in two ways: the largest degree drops from $k_{\max}$ to a smaller $k'_{\max}$, and the nodes that were linked to the removed hubs lose those links. Seen from the survivors, losing these links is like random link removal, so the attack can be mapped back onto the random-failure calculation. For a power law the threshold solves (Eq. 8.12, Cohen et al. 2001)

$$f_c^{\frac{2-\gamma}{1-\gamma}} = 2 + \frac{2-\gamma}{3-\gamma}\,k_{\min}\Big(f_c^{\frac{3-\gamma}{1-\gamma}} - 1\Big).$$
$f_c$
here the fraction of highest-degree nodes removed; a few per cent to some tens of per cent

Worked example: $\gamma = 2.5$, $k_{\min} = 2$.

  1. The exponents are $\frac{2-\gamma}{1-\gamma} = \frac13$ and $\frac{3-\gamma}{1-\gamma} = -\frac13$; the coefficient is $\frac{2-\gamma}{3-\gamma} = -1$.
  2. With $x = f_c^{1/3}$ the equation reads $x = 2 - 2\,(1/x - 1)$, that is $x^2 - 4x + 2 = 0$.
  3. The root below 1 is $x = 2 - \sqrt2 = 0.586$, so $f_c = x^3 = 0.20$.
  4. Meaning: the same network that survives the random loss of almost all its nodes falls apart once its top 20% are removed (exactly: 14%, as the figure below shows).

Robust yet fragile: a random failure almost never hits a hub; an attack removes the hubs that hold everything together. The property that protects the network, its hubs, is also its Achilles' heel.

Cascading failures

So far nodes failed independently. In real systems a failure moves load onto neighbours, which may then fail too: the 2003 blackout, flight delays spreading through airline hubs, retweet cascades. Their sizes have no typical scale: the probability of a cascade of size $s$ is a power law

$$p(s) \sim s^{-\alpha},$$

with measured exponents between 1.5 and 2 for blackouts, Twitter cascades and earthquakes. Cascades need three ingredients: a flow on the network, a local breakdown rule, and a redistribution of the load when something fails.

Failure propagation model (Watts 2002). Every node has the same threshold $\varphi$: a healthy node fails as soon as a fraction $\varphi$ of its neighbours have failed. Start with one failed node and let the failure spread.

Branching model. To see where the exponent comes from, treat a cascade as a tree: the first failure is the root, and each failed node triggers $k$ new failures with probability $p_k$. If on average each failure causes fewer than one new failure, avalanches die out (subcritical); more than one, they grow forever (supercritical); exactly one, they have sizes of every scale (critical). At the critical point

$$\alpha = \begin{cases} 3/2 & p_k \text{ narrow, or a power law with } \gamma \ge 3\\ \gamma/(\gamma-1) & p_k \sim k^{-\gamma},\ 2 < \gamma < 3 \end{cases}$$
$\alpha$
avalanche exponent; $3/2$ is the first-return time of a random walk, which counts active failures
$\gamma$
degree exponent of the network the cascade runs on

Building robustness

Suppose links cost money, so the average degree $\langle k\rangle$ is fixed. Random failures are best resisted by the largest $\langle k^2\rangle$, attacks by having no hubs at all. To resist both, maximise the sum of the two thresholds (Eq. 8.16)

$$f_c^{tot} = f_c^{rand} + f_c^{targ}.$$

The optimum is a bimodal degree distribution (Eq. 8.17–8.18): a fraction $r$ of nodes with degree $k_{\max}$ and the rest with degree $k_{\min}$,

$$p_k = (1-r)\,\delta(k - k_{\min}) + r\,\delta(k - k_{\max}), \qquad r = \frac1N, \qquad k_{\max} \approx A\,N^{2/3}.$$
$r$
share of hub nodes; at the optimum a single hub
$k_{\max}$
degree of the hub; $A$ is a constant

Worked example: the cost of a backup. A star with a hub and 6 spokes has 6 links among 7 nodes: cost $\langle k\rangle = 12/7$. One attack on the hub isolates every spoke. Linking the spokes into a ring adds 6 links, $\langle k\rangle = 24/7$: the cost doubles, but the network survives the loss of its hub. Try the bimodal option in Choose a degree distribution: with $r = 1/N$ and a large enough $k_{\min}$, failure and attack curves nearly coincide.

Halting cascades (Box 8.4). New lines take years to build; a cascade takes seconds. Simulations show that removing a few well-chosen components right after the first failure (lightly loaded nodes, links with large excess load near the failure) can stop the cascade, as firefighters burn a firebreak.

Robust, resilient, redundant (Box 8.5). A system is robust if it keeps working when components fail, resilient if it adapts its mode of operation to keep working, and redundant if parallel components can stand in for missing ones. Many independent paths between node pairs make networks redundant.

  • Reverse of the giant-component transition: for a random network $\kappa = 2$ is $\langle k\rangle = 1$.
  • Builds on the divergent $\langle k^2\rangle$ for $\gamma < 3$.
  • Same formula as the epidemic threshold: $T_c = 1 - f_c$.
  • Modified by degree correlations: linked hubs back each other up.

  1. Both
  2. Only the node with 3 neighbours: $1/3 \ge 0.2$, while $1/10 < 0.2$
  3. Only the node with 10 neighbours
  4. Neither
Low-degree nodes are the vulnerable ones: a single failed neighbour is a large share of their links. Dense networks protect their nodes, which is why cascades die out when $\langle k\rangle$ is large.

Cascades on a network with degree exponent $\gamma = 2.2$ follow the branching model at its critical point, so $p(s) \sim s^{-\alpha}$ with $\alpha = \gamma/(\gamma - 1)$. What is $\alpha$, and what does it mean compared with a random network?

  1. $\alpha = 1.5$, the same as for a random network
  2. $\alpha = 2.2$: cascades are as broad as the degrees
  3. $\alpha \approx 1.83$: the tail falls faster than for a random network ($1.5$), but there is still no typical cascade size
  4. $\alpha \approx 1.83$: large cascades become impossible
$2.2/1.2 = 1.83$. Measured exponents for blackouts, retweets and earthquakes lie between 1.5 and 2, the range the branching model predicts.

  2. Poisson
  3. A power law with $\gamma = 2.1$
