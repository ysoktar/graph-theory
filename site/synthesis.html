Key messages

  1. Random networks are the null model: right on the giant component and small worlds, wrong on hubs and clustering.
  2. Real degree distributions are heavy-tailed. Plot with log bins or the CCDF; fit by maximum likelihood with a goodness-of-fit test.
  3. Heavy tails mean large $\langle k^2\rangle$: this, not the exact tail shape, drives robustness (Ch 8) and spreading (Ch 10).
  4. Degree-preserving randomization separates what the degrees explain from what they do not.
  5. Check everything: software defaults (powerlaw's $\gamma \le 3$), approximations, and generalisations from one network.

Self-test

Random network, $N = 10^4$, $\langle k\rangle = 2$. Most likely?

  1. No giant component
  2. Connected
  3. A giant component with about 80% of nodes
  4. A hub with about 100 links
$S = 1 - e^{-2S}$ gives $S \approx 0.80$.

A linearly binned log-log $p_k$ flattens into a horizontal tail. Why?

  1. A cutoff
  2. Tail degrees are held by single nodes: $p_k = 1/N$
  3. Assortativity
  4. $\gamma \approx 2$
Sampling noise; log-binning or the CCDF removes it.

With $\gamma \le 3$ imposed: $\hat\gamma = 2.95$, $k_{\min} = 36$. Unrestricted: $\hat\gamma = 3.40$, $k_{\min} = 70$. Report?

  1. 2.95, since scale-free means $\gamma < 3$
  2. 3.18
  3. Neither; use least squares
  4. 3.40
The restriction excluded the best fit; the unrestricted one has smaller KS distance.

Randomized: clustering 0.6 → 0.002, distance 5.3 → 4.4. Conclusion?

  1. Clustering is not explained by degrees; triangles lengthen paths
  2. The swaps changed degrees
  3. The network is random
  4. Clustering alone sets distances
Links that formed triangles become shortcuts after randomization.

Which survives 50% random failures best (same $\langle k\rangle = 1.5$)?

  1. Random network
  2. Square lattice
  3. Scale-free, $\gamma = 2.3$
  4. Ring
Large $\langle k^2\rangle$ gives $\kappa \gg 2$, so $f_c$ is near 1.

Which quantity sets the Molloy–Reed criterion, the epidemic threshold and the neutral $k_{nn}$?

  1. $\langle k\rangle$
  2. $\kappa = \langle k^2\rangle/\langle k\rangle$
  3. $C$
  4. $\gamma$
All three follow a link: the node at its end has mean degree $\kappa$.

Why is a scale-free network both robust to failures and vulnerable to epidemics?

  1. It is not; they are different networks
  2. High clustering
  3. Short distances
  4. One large $\kappa$: $f_c = 1 - 1/(\kappa-1)$ and $T_c = 1/(\kappa-1)$
Both are percolation thresholds: $T_c = 1 - f_c$.

Modularity, assortativity and degree-preserving randomization share what?

  1. The configuration model as null model
  2. The random network $G(N, p)$
  3. The BA model
  4. The fitness model
Each compares a network with random wiring of its own degrees.

Which model contains BA as the special case of equal $\eta$?

  1. Configuration model
  2. Random network
  3. Fitness model
  4. Percolation
Equal $\eta$ cancel in $\Pi_i = \eta_i k_i/\sum_j \eta_j k_j$.

BA explains the power law. What does it still miss?

  1. A giant component
  2. High clustering and $\gamma \ne 3$
  3. Small distances
  4. Hubs
BA clustering vanishes as $(\ln N)^2/N$ and $\gamma = 3$ always; fitness and other ingredients fix the exponent.
