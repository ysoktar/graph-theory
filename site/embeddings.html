Graph machine learning & node embeddings

Machine-learning models expect vectors, not networks. A node embedding maps each node to a vector so that nodes close in the network are close in space.

  • Earlier chapters describe networks with a few numbers ($\langle k\rangle$, $C$, $\gamma$); prediction needs a description of every node.
  • Embeddings feed standard classifiers: label nodes, find communities, predict missing links.
  • Graph neural networks learn the description for the task.

Spectral embedding

Use eigenvectors of the normalised Laplacian

$$\mathcal L = I - D^{-1/2} A D^{-1/2}.$$
$A$
adjacency matrix (Ch 2)
$D$
diagonal matrix of degrees
$I$
identity matrix

Eigenvectors with small eigenvalues vary little across links. The second (the Fiedler vector) is the best two-group cut, relaxed to real values; its sign splits the network (spectral bisection). Further eigenvectors add coordinates.

Random-walk embeddings

DeepWalk (Perozzi, Al-Rfou and Skiena 2014) and node2vec (Grover and Leskovec 2016) treat short random walks as sentences and nodes as words, then run word2vec: nodes that co-occur in walks get similar vectors. node2vec's two parameters tune walks between local (breadth-first) and exploratory (depth-first).

The club split between Mr. Hi (node 0) and the officer (node 33). Both embeddings recover it from the links alone: one coordinate's sign places nearly everyone; the exceptions sit between the groups in the network too.

Graph neural networks

A GNN layer passes messages: each node combines its vector with its neighbours' (graph convolutional network, Kipf and Welling 2017):

$$h_v^{(l+1)} = \sigma\Big(W^{(l)} \cdot \operatorname{mean}\{h_u^{(l)} : u \in \{v\} \cup N(v)\}\Big).$$
$h_v^{(l)}$
vector of node $v$ after layer $l$
$N(v)$
neighbours of $v$
$W^{(l)}$
learned weight matrix
$\sigma$
non-linearity (e.g. ReLU)

After $l$ layers a node sees nodes up to distance $l$. The figure drops $W$ and $\sigma$ to show the averaging alone.

Link prediction

Networks are measured incompletely (untested protein pairs, undeclared friendships). Rank unlinked pairs $u, v$ by a score:

  • Common neighbours $|N(u) \cap N(v)|$; Jaccard divides by $|N(u) \cup N(v)|$.
  • Adamic–Adar $\sum_{w \in N(u)\cap N(v)} 1/\ln k_w$: shared low-degree neighbours count more.
  • Preferential attachment $k_u k_v$, from the BA model.

Evaluate by hiding links: AUC = probability that a hidden link outscores a random non-link (ties ½). 0.5 is guessing, 1 perfect.

  • Generalizes spectral bisection: one eigenvector splits, several embed.
  • Common neighbours rely on clustering: they work only where triangles close.
  • Preferential attachment score applies the BA rule to prediction.
  • Over-smoothing is a random walk reaching equilibrium, the same walk DeepWalk samples.

Common-neighbour scores assume friends of friends become friends. Where should that fail?

It suits clustered social networks (collaboration, phone calls). Proteins sharing a partner often compete for the same binding site and do not bind each other; Kovács et al. (Nat. Commun. 2019) count paths of length three instead. The power grid has almost no triangles.

After many plain-averaging layers, every node has almost the same value. This is

  1. overfitting
  2. over-smoothing
  3. percolation
  4. assortativity
Repeated averaging converges to a constant; the starting labels are lost. Residual connections and attention counter it.

A link predictor has AUC = 0.5. It

  1. finds half the hidden links
  2. ranks perfectly
  3. does no better than guessing
  4. ranks backwards
A hidden link outscores a non-link only half the time.

Adamic–Adar weights of a shared neighbour with degree 2 vs 100?

  1. Equal
  2. 0.5 vs 0.01
  3. Hub weighs more
  4. 1.44 vs 0.22
$1/\ln 2 = 1.44$, $1/\ln 100 = 0.22$: sharing a hub is weak evidence.

Common neighbours score AUC 0.96 on collaboration but about 0.56 on proteins. Why?

  1. Protein data are wrong
  2. Collaboration is highly clustered; proteins sharing a partner rarely bind
  3. Proteins form a smaller network
  4. Proteins are directed
Co-authors of one person often co-author together (triangles); proteins do not follow triadic closure.
