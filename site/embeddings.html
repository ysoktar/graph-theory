Graph machine learning & node embeddings

Network science summarises a whole network in a few numbers. Machine learning needs a description of every node, pair or graph, as a vector a classifier can use. This page builds that description twice: first by hand (features), then by learning it (embeddings and graph neural networks).

  • Earlier chapters describe networks with a few numbers ($\langle k\rangle$, $C$, $\gamma$); prediction needs a description of every node.
  • Hand-made features reuse what the course already measures: degree, clustering, paths, random walks.
  • Embeddings learn the features instead; graph neural networks learn them for the task at hand.

Every task needs a vector per node (or pair, or graph). The classic pipeline computes it by hand and feeds it to a standard model such as logistic regression or a random forest.

Hand-made features: nodes

How important is a node? Each centrality answers a different version of the question.

Worked example 1: eigenvector centrality of a star. A hub with $n$ leaves.

  1. Each leaf's only neighbour is the hub: $\lambda c_{\text{leaf}} = c_{\text{hub}}$. The hub has $n$ leaf neighbours: $\lambda c_{\text{hub}} = n\,c_{\text{leaf}}$.
  2. Multiply: $\lambda^2 = n$, so $\lambda = \sqrt n$ and $c_{\text{leaf}} = c_{\text{hub}}/\sqrt n$.
  3. With 4 leaves: $\lambda = 2$, leaves score half the hub. Degree would say a quarter: a leaf gains from its one important neighbour.

Worked example 2: PageRank by hand. Directed links $A \to B$, $A \to C$, $B \to C$, $C \to A$, $D \to C$; start from $r = \frac14$ each.

  1. Simplified PageRank ($d = 1$): each node splits its score equally over its out-links. Iteration 1: $A$ receives all of $C$'s $0.25$; $B$ half of $A$'s, $0.125$; $C$ half of $A$'s plus all of $B$'s and $D$'s, $0.625$; $D$ receives nothing, $0$.
  2. Iteration 2: $A = 0.625$, $B = 0.125$, $C = 0.250$, $D = 0$. It converges to $A = 0.4$, $B = 0.2$, $C = 0.4$, $D = 0$.
  3. With $d = 0.85$ every node first gets $0.15/4 = 0.0375$: $D$ keeps $0.038$ instead of 0, and the result is $A = 0.373$, $B = 0.196$, $C = 0.394$. Teleporting stops scores from draining into dead ends and keeps the walk from getting trapped.

Hand-made features: pairs of nodes

For link prediction, score each unlinked pair $u, v$:

  • Distance $d_{uv}$: short is likely, but it ignores how many paths there are.
  • Common neighbours $|N(u) \cap N(v)|$; Jaccard divides by $|N(u) \cup N(v)|$.
  • Adamic–Adar $\sum_{w \in N(u)\cap N(v)} 1/\ln k_w$ and resource allocation $\sum_w 1/k_w$: a shared low-degree neighbour says more than a shared hub.
  • Preferential attachment $k_u k_v$, from the BA model.
  • Katz index: count all walks between $u$ and $v$, damping long ones:
    $$S_{uv} = \sum_{\ell \ge 1}\beta^\ell (A^\ell)_{uv}, \qquad S = (I - \beta A)^{-1} - I, \qquad \beta < 1/\lambda_{\max}.$$

The first scores are local (they see only shared neighbours, so they give 0 to pairs at distance 3 or more); Katz is global.

Worked example 3: Katz on a square. Nodes $A, B, C, D$ in a 4-cycle; $\lambda_{\max} = 2$, so $\beta < 0.5$.

  1. Opposite corners $A, C$ share 2 neighbours but are not linked. Walks from $A$ to $C$: 2 of length 2, 8 of length 4, and so on (none of odd length).
  2. $\beta = 0.1$: $S_{AC} = 2(0.01) + 8(0.0001) + \dots = 0.021$. Adjacent corners: $S_{AB} = 0.104$.
  3. $\beta = 0.4$: $S_{AC} = 0.89$, $S_{AB} = 1.11$. Close to $1/\lambda_{\max}$ long walks dominate and the scores blow up; at $\beta \ge 0.5$ the sum diverges.

Evaluate by hiding links: AUC = probability that a hidden link outscores a random non-link (a tie counts as ½). 0.5 is guessing, 1 perfect.

Hand-made features: whole graphs

To classify graphs we need to compare them. Counting small subgraphs (graphlets) works but is expensive. The Weisfeiler–Lehman (WL) method is cheap: give every node the same colour, then repeatedly recolour each node by its own colour and the multiset of its neighbours' colours:

$$c^{(t+1)}(v) = \operatorname{hash}\Big(c^{(t)}(v),\ \{\!\{c^{(t)}(u) : u \in N(v)\}\!\}\Big).$$

After $t$ rounds a node's colour summarises its neighbourhood up to distance $t$. Two graphs whose colour counts differ are certainly different (not isomorphic); the counts, as a vector, are the WL graph features. If the counts never differ, WL cannot tell the graphs apart, even when they are different.

Worked example 4: WL by hand. Graph 1 is a path of 5 nodes, $a{-}b{-}c{-}d{-}e$; graph 2 is a triangle plus a separate link. Both have degrees $\{1, 1, 2, 2, 2\}$.

  1. Round 1 (colour = degree): both graphs have two nodes of colour 1 and three of colour 2. Not yet distinguished.
  2. Round 2 (own colour + neighbours' colours): path: $a, e \to (1; 2)$, $b, d \to (2; 1, 2)$, $c \to (2; 2, 2)$. Triangle plus link: link ends $\to (1; 1)$, triangle nodes $\to (2; 2, 2)$.
  3. The colour counts now differ, so the graphs are different. But a 6-cycle and two triangles stay identical forever: every node has degree 2 and two degree-2 neighbours in both.

Node embeddings: learning the features

Hand-made features must be designed for each task. A node embedding learns a vector $\mathbf z_v \in \mathbb R^d$ for every node, with $d$ small (2 to a few hundred), so that similar nodes get similar vectors. Every method has the same three parts:

  1. Encoder $\text{ENC}(v) = \mathbf z_v$. For "shallow" embeddings it is a lookup in a learned table: $\mathbf z_v = Z\mathbf e_v$, with one column of $Z$ per node.
  2. Decoder $\text{DEC}(\mathbf z_u, \mathbf z_v)$, usually the dot product $\mathbf z_u^{T}\mathbf z_v$.
  3. A notion of similarity in the network, which the decoder should reproduce: $\mathbf z_u^{T}\mathbf z_v \approx \text{similarity}(u, v)$. The choice of similarity is what distinguishes the methods.

Spectral embedding: similarity = being linked

Place linked nodes close: minimise $\sum_{(u,v)} \lVert\mathbf z_u - \mathbf z_v\rVert^2$ over the links, with a constraint that stops all vectors collapsing to one point. The solution is given by eigenvectors of the normalised Laplacian with the smallest eigenvalues (Laplacian eigenmaps):

$$\mathcal L = I - D^{-1/2} A D^{-1/2}.$$
$A$
adjacency matrix (Ch 2)
$D$
diagonal matrix of degrees
$I$
identity matrix

The first eigenvector is trivial (constant after rescaling). The second, the Fiedler vector, is the best two-group cut relaxed to real values: its sign splits the network (spectral bisection). Further eigenvectors add coordinates.

Random-walk embeddings: similarity = appearing on the same walks

DeepWalk (Perozzi, Al-Rfou and Skiena 2014) and node2vec (Grover and Leskovec 2016) run short random walks from every node and call $v$ a context of $u$ if it appears within a window of $u$ on a walk. Then they maximise the probability of the observed contexts:

$$\max_Z \sum_u \sum_{v \in N_R(u)} \log P(v \mid \mathbf z_u), \qquad P(v \mid \mathbf z_u) = \frac{e^{\mathbf z_u^{T}\mathbf z_v}}{\sum_{n} e^{\mathbf z_u^{T}\mathbf z_n}}.$$
$N_R(u)$
the contexts of $u$ collected from the walks (with repetitions)
softmax
turns dot products into probabilities; its denominator sums over all $N$ nodes

The denominator costs $O(N)$ for every pair, too slow. Negative sampling replaces it: reward the true context and penalise $k$ random nodes (typically 5 to 20, drawn more often for high degree):

$$\log \sigma(\mathbf z_u^{T}\mathbf z_v) + \sum_{i=1}^{k}\log \sigma(-\mathbf z_u^{T}\mathbf z_{n_i}), \qquad \sigma(x) = \frac{1}{1 + e^{-x}}.$$

This is word2vec with walks as sentences and nodes as words.

The club split between Mr. Hi (node 0) and the officer (node 33). Both embeddings recover it from the links alone: one coordinate's sign places nearly everyone; the exceptions sit between the groups in the network too.

node2vec's biased walk. A walk that just moved from $t$ to $v$ picks the next node $x$ with weight

$$\alpha_{pq}(t, x) = \begin{cases} 1/p & d_{tx} = 0 \ (\text{back to } t) \\ 1 & d_{tx} = 1 \ (\text{a common neighbour of } t \text{ and } v) \\ 1/q & d_{tx} = 2 \ (\text{further away}) \end{cases}$$

Small $q$ pushes the walk outward (depth-first): embeddings capture communities. Large $q$ keeps it local (breadth-first): embeddings capture structural roles, such as "a hub" or "a bridge", wherever they are. Small $p$ makes it backtrack. $p = q = 1$ is DeepWalk.

Worked example 5: one node2vec step. The walk came from $t$ to $v$. $v$'s neighbours are $t$, $x_1$ (also linked to $t$) and $x_2$, $x_3$ (not linked to $t$). Take $p = 2$, $q = 0.5$.

  1. Weights: $t$: $1/p = 0.5$; $x_1$: 1; $x_2$, $x_3$: $1/q = 2$ each. Total 5.5.
  2. Probabilities: back to $t$ 9%, to $x_1$ 18%, to $x_2$ or $x_3$ 36% each. The walk heads away from where it came: depth-first.

Using embeddings, and their limits

  • Node classification: train a classifier on $\mathbf z_v$ for the labelled nodes, predict the rest.
  • Link prediction: score a pair by $\mathbf z_u^{T}\mathbf z_v$, or train a classifier on $\mathbf z_u \odot \mathbf z_v$ (element-wise product) or on the two vectors concatenated.
  • Graph classification: sum or average the node vectors.

Shallow embeddings have three limits: one learned vector per node ($O(Nd)$ parameters, nothing shared between nodes); they are transductive (a new node has no vector until everything is retrained); and they ignore node attributes. Graph neural networks fix all three.

Graph neural networks

A GNN layer passes messages: each node combines its vector with its neighbours' (graph convolutional network, Kipf and Welling 2017):

$$h_v^{(l+1)} = \sigma\Big(W^{(l)} \cdot \operatorname{mean}\{h_u^{(l)} : u \in \{v\} \cup N(v)\}\Big).$$
$h_v^{(l)}$
vector of node $v$ after layer $l$; $h_v^{(0)}$ are the node's attributes
$N(v)$
neighbours of $v$
$W^{(l)}$
learned weight matrix, shared by all nodes
$\sigma$
non-linearity (e.g. ReLU)
  • Shared weights: the same $W^{(l)}$ for every node, so the model is inductive: it computes a vector for a node it never saw.
  • Depth = reach: after $l$ layers a node sees nodes up to distance $l$. With the small-world distances of Ch 3, a few layers already cover most of the network.
  • Over-smoothing: many layers average everything into the same vector (the figure below).
  • Expressiveness: a message-passing GNN cannot distinguish two graphs that the WL test cannot; the GIN architecture matches WL exactly (Xu et al. 2019).

Common-neighbour scores assume friends of friends become friends. Where should that fail?

It suits clustered social networks (collaboration, phone calls). Proteins sharing a partner often compete for the same binding site and do not bind each other; Kovács et al. (Nat. Commun. 2019) count paths of length three instead. The power grid has almost no triangles.

Repeated averaging converges to a constant; the starting labels are lost. Residual connections and attention counter it.

In simplified PageRank (no teleporting, $d = 1$), node $D$ has out-links but no in-links. What is its score after the first iteration, and why does real PageRank use $d < 1$?

  1. It keeps its starting score, because it has out-links
  2. It becomes the largest, because it gives score to others
  3. It drops to 0; teleporting gives every node a floor of $(1-d)/N$ and stops the walk from getting trapped
  4. It is undefined; $d < 1$ only makes the computation faster
A node's new score is what flows in along links. Without teleporting, nodes without in-links drop to 0 and dead ends or closed loops can trap the walk; $d = 0.85$ fixes both.

The largest eigenvalue of a network's adjacency matrix is $\lambda_{\max} = 4$. For which damping $\beta$ is the Katz index $\sum_{\ell} \beta^\ell (A^\ell)_{uv}$ defined?

  1. $\beta < 1$
  2. $\beta < 0.25$
  3. $\beta > 0.25$
  4. Any $\beta > 0$
Walk counts grow like $\lambda_{\max}^\ell$, so $\beta^\ell\lambda_{\max}^\ell$ must shrink: $\beta < 1/\lambda_{\max} = 0.25$.
