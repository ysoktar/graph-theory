Degree, average degree and degree distribution

How many links does a node have, and how unevenly are links shared out? A node's degree and the network's degree distribution answer this. Random and scale-free networks (Parts II and III) differ above all in this distribution, and it decides robustness and spreading.

Degree and average degree

The degree $k_i$ of node $i$ is its number of links. Summing all degrees counts each link twice (handshaking), so

$$L = \frac{1}{2}\sum_{i=1}^{N} k_i, \qquad \langle k\rangle = \frac{1}{N}\sum_{i=1}^{N} k_i = \frac{2L}{N}.$$
$N$, $L$
number of nodes, of links
$k_i$
degree of node $i$
$\sum_{i=1}^{N}$
sum over all nodes, $k_1 + \dots + k_N$
$\langle k\rangle$
average degree; $\langle\cdot\rangle$ = average over nodes

In a directed network (WWW, email) links have a direction. Node $i$ has an in-degree $k_i^{\text{in}}$ and an out-degree $k_i^{\text{out}}$, with $k_i = k_i^{\text{in}} + k_i^{\text{out}}$. Each link leaves one node and enters one:

$$L = \sum_{i} k_i^{\text{in}} = \sum_{i} k_i^{\text{out}}, \qquad \langle k^{\text{in}}\rangle = \langle k^{\text{out}}\rangle = \frac{L}{N}.$$
$k_i^{\text{in}}$
links pointing to $i$
$k_i^{\text{out}}$
links leaving $i$

The degree distribution gives the share of nodes with each degree:

$$p_k = \frac{N_k}{N}, \qquad \sum_{k} p_k = 1, \qquad \langle k\rangle = \sum_{k} k\,p_k .$$
$N_k$
number of nodes with degree $k$
$p_k$
share of nodes with degree $k$ = probability that a random node has degree $k$
$\sum_k k\,p_k$
average degree computed from the distribution
  • $\langle k\rangle$ needs only two counts, $N$ and $L$.
  • $p_k$ alone predicts the largest hub, robustness and epidemic thresholds, without the full wiring.
  • Comparing $p_k$ with a random network's shows that real networks are not random.

Build a network

  • Each link raises two degrees by one, so $\sum_i k_i$ is even and odd-degree nodes come in pairs. Try to break this.
  • Directed: $\sum k^{\text{in}} = \sum k^{\text{out}} = L$, however unbalanced single nodes are.
  • Star: the hub has $k = N-1$, yet $\langle k\rangle < 2$. Averages hide hubs.

A first real network: Zachary's karate club

Wayne Zachary followed the 34 members of a university karate club (1970–72); a link means two members regularly met outside the club. A conflict split the club between the instructor ("Mr. Hi", node 0) and the president (node 33); colours show the sides.

$\langle k\rangle = 2 \times 78/34 \approx 4.59$. $N_2 = 11$, so $p_2 = 11/34 \approx 0.32$. Median degree 3 < mean, pulled up by $k_0 = 16$, $k_{33} = 17$.

A large network: scientific collaboration

The science collaboration network (book Table 4.1): $N = 23{,}133$ scientists, linked if they co-authored a paper. Its $p_k$ on linear axes:

The bars seem to end near $k \approx 50$, yet $k_{\max} = 279$: each hub is one node in 23,133. Switch to a Log axis (equal steps = equal ratios) to see them. Part III shows how to plot $p_k$ properly.

78% of scientists have $k \le 10$; 28 have $k \ge 100$. Standard deviation $\sigma_k = 10.6 > \langle k\rangle = 8.08$.

The median scientist has 5 collaborators, the average has 8.1, and the maximum is 279. Which of these numbers would you report as "the typical number of collaborators", and why?

A few very large values pull the mean up; the median (5) describes a typical node better. Here the spread $\sigma_k$ exceeds $\langle k\rangle$, so no single number is "typical": the idea behind the name scale-free (Chapter 4).
  • Builds on Königsberg: $\sum_i k_i = 2L$, divided by $N$.
  • Read from the adjacency matrix (row sums); sparsity compares $\langle k\rangle$ with $N-1$.
  • Random-network prediction: Poisson $p_k$; real networks deviate with heavy tails.
  • Heavy tails → power laws → hubs and large $\langle k^2\rangle$ (No typical degree).

$N = 10$, $L = 15$. What is $\langle k\rangle$?

  1. 1.5
  2. 3
  3. 30
  4. 0.67
$\langle k\rangle = 2L/N = 30/10 = 3$.

Which degree sequence can no network have?

  1. 2, 2, 2
  2. 3, 1, 1, 1
  3. 2, 2, 1
  4. 1, 1, 1, 1
Degrees sum to $2L$, an even number; $2+2+1 = 5$ is odd. An even sum is necessary, not sufficient: 3, 3, 3, 1 is impossible too.

A directed network of 5 pages has 8 links. Average in-degree?

  1. 1.6
  2. 3.2
  3. 0.8
  4. It depends on the wiring
In-degrees sum to $L = 8$, so $\langle k^{\text{in}}\rangle = 8/5 = 1.6$, equal to $\langle k^{\text{out}}\rangle$.

11 of the 34 karate members have degree 2. What is $p_2$?

  1. $2/34$
  2. $11/34 \approx 0.32$
  3. 11
  4. $1/11$
$p_2 = N_2/N = 11/34 \approx 0.32$: a random member has degree 2 with probability 0.32.

  4. 5.5
